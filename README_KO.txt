옆자리 고양이 2.0.0
Windows 10/11 x64에서 실제 시간으로 함께 지내는 데스크톱 반려동물

1. 실행과 기본 조작
ZIP 압축을 풀고 YeopjariCat.exe를 실행하세요. 별도 파이썬이나 게임 엔진 설치는 필요 없습니다.
update-feed.txt를 실행 파일 옆에 함께 보관하면 기존 프로그램 업데이트 기능을 사용할 수 있습니다.
실행할 때 포인터가 있는 모니터의 작업표시줄 위에서 시작합니다.
첫 번째 동물을 끌어 다른 모니터로 옮길 수 있고, 가볍게 클릭하면 쓰다듬습니다.
동물이나 작업표시줄 알림 영역 아이콘을 오른쪽 클릭하면 메뉴가 열립니다.
기존 생일·성장·체형·친밀도·돌봄 기억·성격·캐릭터·의상·소리·업데이트 설정을 이어갑니다.

Ctrl + Alt + F : 첫 번째 동물에게 밥 주기
Ctrl + Alt + T : 첫 번째 동물에게 츄르 주기
Ctrl + Alt + H : 두 동물 잠깐 숨기기 / 다시 보이기
Ctrl + Alt + B : 박스 꺼내기

다른 프로그램과 단축키가 겹치면 우클릭 메뉴에서 같은 기능을 선택하세요.
‘이 자리에서 쉬기’는 자동 이동을 멈추고 조용한 행동을 이어갑니다.
동물이 보이지 않으면 Ctrl+Alt+H와 작업표시줄의 숨겨진 알림 영역 아이콘을 확인하세요.

2. 두 마리 함께 키우기
우클릭 → ‘두 마리 함께 키우기’ → ‘두 번째 동물 만나기’를 선택하세요.
두 번째 동물은 선택하기 전에는 자동으로 생기지 않습니다.
각자 별도 창과 물리 몸체, 생일·성장·체형·성격·친밀도·밥과 간식 기록을 갖습니다.
두 번째 동물을 직접 오른쪽 클릭하면 그 동물의 밥·간식, 캐릭터, 옷장, 휴식과 성장 기록을 선택할 수 있습니다.
주 메뉴의 ‘두 마리 함께 키우기’에서도 두 번째 동물에게 먹이를 줄 수 있습니다.
단축키 F/T는 첫 번째 동물에게 적용되므로 두 번째 동물은 해당 메뉴를 사용하세요.

가까이에서 냄새를 맡거나 따라 걷고, 함께 뛰거나 앞발 장난을 치고, 나란히 잠들 수 있습니다.
첫 번째 동물이 먹이를 받으면 배고픈 동물이 곁으로 다가와 먹이를 기다리기도 합니다.
실제로 받아먹은 동물에게만 먹은 횟수와 포만감이 기록됩니다.
한 동물이 창 위에 있으면 다른 동물도 거리를 계산해 따라 올라갈 수 있습니다.
‘두 번째 동물 잠시 쉬게 하기’로 표시를 꺼도 기록을 삭제하거나 생일을 다시 만들지 않습니다.

3. 캐릭터와 옷장
캐릭터 선택은 총 10종입니다.
크림 치즈냥 / 실버 태비냥 / 까만냥 / 삼색냥 / 샴냥 / 먼치킨냥 /
옆자리 멍멍이 / 옆자리 토끼 / 턱시도냥 / 브리티시냥

고양이 8종과 강아지·토끼가 각자의 그림으로 움직입니다.
먼치킨은 점프 높이가 낮고, 샴은 말 걸기와 호기심이 많은 등 이동·점프·먹이 관심에 작은 차이가 있습니다.
캐릭터를 바꿔도 함께한 날짜, 생일, 돌봄 기록과 배운 성향은 유지됩니다.
두 동물은 서로 다른 캐릭터와 의상을 선택할 수 있습니다.

옷장은 미착용을 포함한 13개 선택 항목입니다.
아무것도 안 입기 / 빨간 리본 / 포근한 목도리 / 쪼꼬미 왕관 / 산타 모자 /
붕어빵 모자 / 회사원 넥타이 / 포근한 후드티 / 멋쟁이 선글라스 / 상어 옷 /
공룡 옷 / 할로윈 호박 모자 / 생일 파티 모자

의상은 얼굴·목·몸의 위치, 좌우 반전과 체형을 따라갑니다.
계절 모자는 해당 이벤트 기간에 열립니다. 이미 입고 있는 옷은 이벤트 옵션을 꺼도 유지됩니다.
겨울에는 메뉴에서 목도리를 추천합니다.

4. 오래 함께한 기억과 생활 패턴
밥·츄르·쓰다듬기·놀아준 경험이 각자의 친밀도와 취향에 쌓입니다.
자주 츄르를 받으면 간식을 더 기대하고, 자주 쓰다듬으면 편안한 반응이 늘어납니다.
익숙해진 동물은 먼저 다가오며, 돌봄 방식에 따른 성향 변화는 여러 날에 걸쳐 아주 천천히 일어납니다.
짧은 시간에 클릭을 반복해도 돌봄 경험이 무제한 쌓이지 않습니다.
오랫동안 실행하지 않았다는 이유로 쌓인 친밀도가 사라지거나, 하지 않은 돌봄이 생기지 않습니다.

기존 동물의 생일에서 정해진 성격은 보존합니다.
새로 만나는 동물에는 겁쟁이·개냥이·시크냥·먹보·장난꾸러기·잠보 성향이 생길 수 있습니다.
졸림·심심함·기분·활동 상태도 행동 선택에 반영되며 잠깐 돌보았다고 성격이 갑자기 바뀌지 않습니다.
아침 기지개, 점심의 식사 요청, 오후 활동, 밤의 수면과 가끔 새벽 우다다처럼 시간대별 비중이 달라집니다.
몇 달·1년·5년을 함께하고 친밀도가 쌓이면 오랜 친구에게 보이는 행동이 열립니다.

처음 함께한 실제 시각을 생일로 사용합니다. PC를 꺼 두어도 날짜는 실제 시간으로 흐릅니다.
첫 실제 생일까지 크기가 천천히 자라고, 10년이 지나도 자동으로 죽거나 초기화되지 않습니다.
계속 과식하면 며칠에 걸쳐 통통해지고, 오래 굶으면 마르며 속도와 점프력도 조금 달라집니다.
받아먹은 직후 5분 동안은 밥과 츄르를 연달아 먹지 않고, 배부르면 거절할 수 있습니다.
거절한 먹이는 먹은 횟수나 포만감에 더하지 않습니다.
시계가 뒤로 바뀌어도 기록 시각과 돌봄 제한을 되돌리지 않습니다. Windows 날짜와 시간을 정확히 유지하세요.

5. 창 사이 이동과 커서 놀이
Box2D 3.1.1이 가속·감속·중력·점프·착지와 충돌을 계산합니다.
브라우저·탐색기·메모장처럼 조건이 맞는 일반 창의 윗면을 걸으며 다른 창으로 건너갈 수 있습니다.
높이가 다른 창은 살펴본 뒤 뛰고, 도달할 수 없거나 착지 공간이 부족하면 포기합니다.
사용자가 창을 움직이면 지지면을 따라 균형을 잡고, 창이 닫히면 공중 움직임을 이어 내려옵니다.
창 위의 동물도 클릭·쓰다듬기·우클릭 메뉴를 사용할 수 있으며, 아래 프로그램 영역은 클릭을 통과시킵니다.
창 가장자리에서의 드문 매달리기도 실제 물리 제약을 사용합니다.

‘업무 방해 모드 · 커서와 놀기’는 기본적으로 꺼져 있습니다.
켜면 가까운 커서를 관찰하고, 천천히 추적하고, 냄새를 맡듯 다가가거나 앞발로 잡으려 합니다.
가만히 둔 낮은 커서에는 가끔 다가가 잠깐 앉기도 하며, 포인터를 움직이면 자리를 비웁니다.
커서가 너무 빠르거나 멀리 가면 포기합니다. 포인터를 강제로 움직이거나 클릭을 대신하지 않습니다.
이 옵션을 꺼도 작업표시줄 산책과 일반 창 위 이동은 유지됩니다.
‘이 자리에서 쉬기’를 선택하면 자동 이동도 함께 쉬게 할 수 있습니다.

6. 장난감과 자연스러운 행동
우클릭 → ‘장난감’에서 공·박스·종이봉투·캣닢·깃털 낚싯대·쿠션의 여섯 가지를 꺼낼 수 있습니다.
공은 실제 Box2D 동적 원으로 굴러가며 앞발이 닿을 때 힘을 받고, 벽·바닥과 충돌하며 감속합니다.
박스와 종이봉투에는 다가가 살펴보고 들어가 쉬며, 캣닢 곁에서는 몸을 비비거나 뒹굽니다.
깃털 낚싯대는 앞발로 장난치고, 쿠션에서는 꾹꾹이·휴식·수면을 이어갑니다.
장난감은 고양이가 창 위로 올라가도 작업표시줄 바닥에 남습니다. ‘장난감 치우기’로 정리하세요.

걷기·우다다·점프·배 까기·꼬리 세우기·몸단장·기지개·식빵·꾹꾹이·빼꼼·몸 긁기·재채기를 유지합니다.
웅크리기·옆으로 눕기·식빵잠·배 보이고 자기·앞발에 얼굴 묻기·꼬리로 얼굴 가리기의 여섯 수면 자세를 선택합니다.
창 위에서는 앉아 졸며 고개를 떨구는 모습도 보입니다. 강아지·토끼는 해당 모습에 맞는 자세를 사용합니다.
졸음·하품·잠꼬대 반응도 추가했습니다.
이동 중 앉거나 먹는 동작을 요청하면 실제로 감속하며, 발걸음은 이동 거리에 맞춥니다.
배 까고 뒹굴기는 조용히 진행하며 효과음을 재생하지 않습니다.

희귀 행동에는 펀치나 재채기 후 스스로 놀라기, 작은 박스에 비집고 들어가기,
왕관을 쓰고 우쭐하기, 창 끝 매달리기, 잠깐 사라졌다 반대편에 나타나기 등이 있습니다.
특별 행동은 하루에 0~2회 범위의 기회와 재실행 후에도 유지되는 간격 제한을 사용하므로 매일 보장되지는 않습니다.
화면 금은 잠깐 보이는 장난이며 실제 문서나 화면을 손상시키지 않습니다.

7. 계절·생일·함께한 날
‘계절·기념일 이벤트’는 메뉴에서 켜고 끌 수 있습니다.
PC의 날짜를 바탕으로 크리스마스·할로윈·생일 모자와 함께한 1주·1년·5년 기념 반응을 표시합니다.
기념일 알림과 희귀 행동은 다른 행동·수면·메뉴를 방해하지 않는 때를 기다립니다.
외부 날씨 서비스나 위치 조회는 사용하지 않습니다.

8. 소리
우클릭 → ‘고양이 소리’에서 켜기/끄기와 작게 25%·보통 45%·크게 70%를 선택합니다.
기본 음량은 25%이며 기존 설정을 그대로 이어갑니다. ‘소리 미리 듣기’로 현재 음량을 확인할 수 있습니다.
첫 번째로 제공받은 영상의 짧은 세 구간을 행동 효과음 14개에 배치했습니다.
요청에 따라 그 영상의 처음 구간은 모든 행동에서 제외했고, 배 까기는 무음으로 유지합니다.
피치와 재생 속도를 바꾸지 않고 음량과 시작·끝 페이드를 조절했습니다.
14개는 서로 다른 원본 소리 14개를 뜻하지 않으며, 같은 짧은 구간을 여러 행동에서 재사용합니다.
효과음은 실행 파일에 포함됩니다. 원본 영상이나 전체 추출 음원은 배포하지 않습니다.
소리를 겹쳐 쌓지 않고, 숨김·메뉴·종료 중에는 멈춥니다. 음소거해도 말풍선은 계속 표시합니다.

9. 기록 전체 백업과 PC 이동
모든 사용자 기록은 다음 폴더에 있습니다.
%LOCALAPPDATA%\YeopjariCat
탐색기 주소창에 붙여 넣거나 메뉴의 ‘기록 폴더 열기’를 선택하세요.

첫 번째 동물: pet.ini/pet.bak(생일·성장·돌봄), nutrition.ini/nutrition.bak(몸 상태),
                 memory.ini/memory.bak(친밀도·기억), life.ini/life.bak(기분·성향·이벤트).
두 번째 동물: companion.ini/companion.bak에 별도의 생일·성장·식사·친밀도·기분·외형을 함께 저장합니다.
캐릭터·의상, 소리, 커서 놀이·계절 옵션, 업데이트 설정·알림 기록도 같은 폴더에 있습니다.

‘성장 기록 따로 백업하기…’는 첫 번째 동물의 기존 성장 기록만 내보냅니다.
두 동물의 기억과 설정까지 모두 백업하려면 프로그램을 종료하고 저장 폴더 전체를 복사하세요.
새 PC에서도 프로그램을 종료한 상태에서 같은 경로에 전체 폴더를 복원하세요.
ZIP과 YeopjariCat.exe만 복사하면 사용자 기록은 옮겨지지 않습니다.

새 생활 기록은 기존 생일에 맞춰 자동으로 추가하며, 기존 동물의 생일이나 성격을 다시 뽑지 않습니다.
기억·생활·두 번째 동물의 파일이 손상되면 확인된 백업으로 복구합니다.
복구할 수 없는 파일은 보존하고 해당 기록의 쓰기를 멈춥니다. 두 번째 동물을 새 동물로 덮어쓰지 않습니다.
기존 체형 파일의 복구 규칙과 월별 성장 기록 보관도 유지합니다.
오래 키울수록 가끔 전체 저장 폴더를 별도의 백업 공간에 복사해 두세요.

10. 업데이트
우클릭 → ‘프로그램 업데이트’ → ‘업데이트 확인…’에서 새 버전을 확인하세요.
새 버전이 있으면 변경 내용을 읽고 업데이트를 선택할 수 있습니다.
다운로드 크기·SHA-256·실행 파일의 종류와 버전을 확인하고 기록을 저장한 뒤 교체·재시작합니다.
‘새 버전 자동 알림’은 “프로그램 업데이트 해줘랴 냥!” 말풍선으로 알려 주며,
사용자가 선택하기 전에는 실행 파일을 다운로드하거나 교체하지 않습니다.
인터넷이 없어도 육성 기능은 계속 사용할 수 있습니다.

수동으로 업데이트하려면 실행 중인 고양이를 종료하고 새 ZIP을 풀어 새 실행 파일을 실행하세요.
같은 Windows 계정의 저장 폴더를 그대로 사용합니다. 실행 폴더는 본인에게 쓰기 권한이 있는 곳을 사용하세요.
공식 다운로드: https://github.com/cho-woo/yeopjari-cat/releases/latest
공식 업데이트 주소: https://github.com/cho-woo/yeopjari-cat/releases/latest/download/latest.txt

성장 기록·화면 내용·키보드 입력을 서버로 전송하지 않습니다. 자동 시작프로그램 등록도 하지 않습니다.
업데이트를 확인하거나 다운로드할 때에는 공식 GitHub 주소로 HTTPS 요청을 보냅니다.
검증 범위와 배포 상태는 소스 저장소의 docs/V2_0_0.md를 참고하세요.
Windows 10/11 x64가 대상이며, 자동 검사 결과를 모든 PC에서의 수동 사용 검수로 표현하지 않습니다.
