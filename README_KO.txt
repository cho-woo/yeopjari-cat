옆자리 고양이 1.10.3 — 영상 효과음·이동 물리·창 위 클릭 수정
윈도우 작업표시줄 위에서 함께 지내는 작은 고양이

이 패키지는 v1.10.0의 친밀도·돌봄 기억·생활 패턴과 이동·자세 수정을 포함한 v1.10.3입니다.
기존 생일·성장·체형·캐릭터·의상·소리와 업데이트 설정을 이어서 사용합니다.

1. 실행
ZIP 압축을 풀고 YeopjariCat.exe를 실행하세요.
별도 파이썬이나 게임 엔진 설치는 필요 없습니다.
Windows 10/11 x64를 대상으로 만든 프로그램입니다.
실행할 때 마우스 포인터가 있는 모니터의 작업표시줄 위에서 고양이가 걷고, 쉬고, 잠듭니다.
고양이를 마우스로 끌면 다른 모니터로 옮길 수 있습니다.
창 테두리, 상점, 레벨창, 결제 기능은 없습니다.
작업 중인 창의 키보드 입력을 빼앗지 않습니다.
1.5.0부터 말풍선과 일부 행동에 맞춰 짧은 고양이 소리를 냅니다. 기본 음량은 작게 25%입니다.
1.6.0은 Box2D 물리엔진을 포함해 가속·감속·점프·착지를 계산하고, 발걸음을 이동 거리에 맞춥니다.
1.7.0은 제공받은 효과음 11개를 적용하고, 새 업데이트를 고양이 말풍선으로 알려줍니다.

2. 이전 버전에서 업데이트
1.2.0 이하 버전을 사용한다면 아래 방법으로 한 번 수동 교체하세요.
실행 중인 고양이나 작업표시줄 알림 영역 아이콘을 오른쪽 클릭하고 ‘종료’를 선택하세요.
새 ZIP 파일의 압축을 푼 뒤 새 폴더의 YeopjariCat.exe를 실행하세요.
기존과 같은 %LOCALAPPDATA%\YeopjariCat 폴더의 기록을 이어서 사용합니다.
생일과 성장 기록, 밥과 간식을 준 기록, 선택한 캐릭터는 그대로 유지됩니다.

1.6.0은 업데이트 창의 제목·하단 안내·버튼 한글 깨짐을 수정했습니다.
이미 실행 중인 구버전의 창은 업데이트를 적용하기 전까지 깨진 글자를 표시할 수 있습니다.
불편하다면 고양이를 종료하고 새 ZIP을 풀어 실행하는 수동 교체 방법을 사용하세요.

이번 패키지는 cho-woo/yeopjari-cat의 업데이트 주소가 연결되어 있습니다.
주소가 연결된 1.3.0 이상 버전에서는 프로그램 안에서 업데이트할 수 있습니다.
고양이나 알림 영역 아이콘을 오른쪽 클릭 → ‘프로그램 업데이트’ → ‘업데이트 확인…’을 여세요.
새 버전이 있으면 버전 번호와 변경 내용을 읽고 ‘업데이트’를 선택할 수 있습니다.
다운로드한 파일의 크기, SHA-256, 프로그램 종류와 버전을 확인하고,
성장 기록을 저장한 다음 실행 파일을 교체하고 고양이를 다시 실행합니다.
다운로드 중에는 고양이를 계속 키울 수 있습니다. 인터넷이 없어도 고양이 기능은 계속 작동합니다.

‘새 버전 자동 알림’이 켜져 있으면 실행 약 30초 후, 이후 약 6시간마다 확인합니다.
새 버전이 확인되면 고양이가 두 줄 말풍선으로 “프로그램 업데이트 해줘랴 냥!”이라고 약 6.5초 동안 알려줍니다.
사용자가 선택하기 전에는 다운로드하거나 교체하지 않습니다.
같은 버전은 한 번만 알려주며 재시작해도 알림 기록을 유지합니다.
숨겨져 있거나 자거나 먹거나 점프하거나 메뉴·다른 말풍선이 보일 때는 기다립니다.
소리를 켜 두면 먼저 말 걸 때의 효과음을 함께 냅니다. 다른 소리의 재생·재생 간격도 기다립니다.
이 기능은 1.7.0을 설치한 뒤 그보다 새로운 버전이 공개됐을 때 동작합니다. 최신 버전에는 요청하지 않습니다.
자동 알림은 같은 메뉴에서 끌 수 있고, 설정은 다음 실행에도 유지됩니다.
공식 다운로드: https://github.com/cho-woo/yeopjari-cat/releases/latest
고정 업데이트 주소: https://github.com/cho-woo/yeopjari-cat/releases/latest/download/latest.txt
실행 파일 옆의 update-feed.txt에는 이 주소가 들어 있습니다. 업데이트를 받으려면 함께 보관하세요.
업데이트 주소가 없는 이전 개발용 패키지는 새 ZIP으로 한 번 수동 교체하세요.

실행 폴더에 쓰기 권한이 있어야 교체할 수 있습니다.
바탕화면이나 문서 폴더 등 본인이 수정할 수 있는 폴더에 압축을 풀어 실행하세요.
소스 저장소의 개발·배포 안내는 docs/DEVELOPMENT.md에서 확인할 수 있습니다.

3. 단축키
Ctrl + Alt + F : 밥 주기
Ctrl + Alt + T : 츄르 주기
Ctrl + Alt + H : 잠깐 숨기기 / 다시 보이기

밥을 주면 그릇에서 먹고, 츄르를 주면 길쭉한 파우치 끝의 간식을 핥아 먹습니다.
눈을 뜨고 핥는 모습과 기분 좋게 눈을 감는 모습이 부드럽게 이어집니다.
츄르를 먹는 동작은 약 4.2초 동안 이어지고, 먹은 뒤에는 앞발을 핥으며 몸단장을 합니다.
배부르면 ‘지금은 배불러…’ 같은 말풍선으로 거절할 수 있습니다.
받아먹은 직후 5분 동안은 밥과 츄르를 연달아 먹지 않습니다.
거절한 먹이는 포만감이나 먹은 횟수에 더해지지 않습니다.
다른 프로그램이 같은 단축키를 사용하면 등록되지 않을 수 있습니다.
이때는 고양이나 작업표시줄 알림 영역 아이콘을 오른쪽 클릭해 먹이를 주세요.
종료와 돌아다니기 일시정지도 오른쪽 클릭 메뉴에서 할 수 있습니다.
‘이 자리에서 쉬기’를 선택하면 걷기와 자동으로 벌이는 큰 장난을 멈추고,
그 자리에서 쉬거나 잠들고 앞발을 핥는 등 조용한 행동을 이어갑니다.
쉬는 중에도 가끔 귀를 움찔하거나 꼬리를 위로 세웁니다.

고양이 소리
고양이나 알림 영역 아이콘을 오른쪽 클릭 → ‘고양이 소리’에서 켜거나 끌 수 있습니다.
음량은 작게(25%), 보통(45%), 크게(70%) 중 선택하며 다음 실행에도 유지됩니다.
‘소리 미리 듣기’로 새로 적용한 인사 효과음과 현재 음량을 확인할 수 있습니다.
1.7.0은 제공받은 효과음 11개를 아래처럼 사용합니다.

- 점프: 실제로 도약할 때 짧게 재생합니다.
- 먼저 말 걸기: 시작 인사, 다시 불렀을 때, 캐릭터 변경과 새 업데이트 말풍선에 사용합니다.
- 배고픔·밥 요청: 배고픈 상태에 맞춰 두 종류 중 하나를 재생합니다.
- 밥 먹기: 사료·생선·노가리 소리 중 하나를 선택합니다. 사료 소리를 조금 더 자주 사용합니다.
- 츄르: 츄르 먹는 전용 소리를 사용합니다.
- 귀·꼬리: 수동 동작에는 전용 소리를, 자동 동작에는 가끔 소리를 냅니다.
- 냥냥펀치: 두 효과음 중 하나를 골라 실제 첫 타격에 한 번 재생합니다.

긴 원본은 동작에 맞는 짧은 구간을 사용하고, 앞뒤 무음·음량 차이를 조절했습니다.
먹이 거절, 쓰다듬기의 골골 소리와 잠에서 깰 때의 기존 효과음 세 가지도 함께 사용합니다.
총 14개 효과음은 실행 파일에 포함되어 인터넷이나 별도 음원 파일 없이 재생합니다.
여러 효과음을 겹치거나 쌓아 두지 않으며 일반 소리는 최소 2.5초, 자동 소리는 최소 1분 간격을 둡니다.
걷거나 귀·꼬리를 움직일 때마다 울지는 않습니다. 숨김·음소거·메뉴·종료 시 재생을 멈춥니다.
음소거 상태에도 말풍선은 표시합니다. Windows 전체 음량은 바꾸지 않습니다.

4. 캐릭터 선택
고양이나 작업표시줄 알림 영역 아이콘을 오른쪽 클릭한 뒤 ‘캐릭터 선택’을 여세요.

- ‘크림 치즈냥’: 처음 함께하던 크림색 고양이입니다.
- ‘실버 태비냥’: 사진의 회색 줄무늬와 흰 가슴, 흰 발을 참고한 고양이입니다.

선택한 모습은 다음에 실행할 때도 유지됩니다.
함께 키우던 한 마리의 외형을 바꾸는 기능으로, 생일과 나이, 성격, 돌봄 기록은 이어집니다.
두 캐릭터 모두 걷기, 츄르 먹기, 점프, 귀 움직임과 꼬리 세우기 동작을 할 수 있습니다.

5. 고양이다운 성격과 행동
1.6.0부터 Box2D 3.1.1이 실제 중력, 도약과 바닥·가장자리 충돌을 계산합니다.
출발할 때 서서히 속도를 내고 멈출 때 속도를 줄이며, 실제 이동 거리에 발걸음을 맞춥니다.
물리 계산은 고정된 시간 간격으로 진행하고, 그 사이의 위치를 보간해 표시합니다.
깨어 있는 동안 화면 갱신은 약 60fps를 목표로 하며 PC 성능과 Windows 상황에 따라 달라집니다.
숨김·메뉴·끌기 중에는 물리 진행을 멈추고, 절전에서 돌아와도 밀린 움직임을 한꺼번에 재생하지 않습니다.
잠들어 쉬는 동안은 화면 갱신 빈도를 낮춥니다. 기존의 귀·꼬리·츄르 애니메이션도 이어집니다.

실제 고양이의 습성에서 착안해 호기심, 활동성, 친화성, 장난기가 행동에 반영됩니다.
다시 실행해도 같은 고양이의 성격을 이어갑니다.
대부분은 느긋하게 걷거나 쉬고 잠들며, 가끔 엉뚱하게 행동합니다.

- 걸을 때 발을 옮기는 자세가 부드럽게 이어지고 몸이 살짝 오르내립니다.
- 밥이나 간식을 먹은 뒤 앞발을 핥고 몸단장을 합니다.
- 잠에서 깨면 기지개를 켭니다.
- 주변에 귀를 기울이듯 귀를 쫑긋 움직였다가 편안한 자세로 돌아옵니다.
- 꼬리를 위로 세워 잠깐 유지한 뒤 다시 편하게 내립니다.
- 가까이 움직이는 마우스 포인터를 빤히 보다가 살금살금 다가가거나 짧게 폴짝 뜁니다.
- 가끔 그 자리에서 몸을 낮췄다가 위로 점프하고 다시 착지합니다.
- 가끔 갑자기 우다다 달리거나 자기 꼬리를 쫓습니다.
- 시간대와 나이에 따라 활동과 휴식의 비중이 조금씩 달라집니다.
- 고양이를 가볍게 클릭하면 쓰다듬은 뒤의 반응을 볼 수 있습니다.

새 동작을 바로 보고 싶다면 오른쪽 클릭 메뉴에서 선택하세요.

- ‘점프 한 번 보기’: 그 자리에서 몸을 낮췄다가 위로 폴짝 뜁니다.
- ‘귀 움직여 보기’: 약 2.2초 동안 귀를 쫑긋 움직입니다.
- ‘꼬리 세워 보기’: 약 3.4초 동안 꼬리를 올리고 잠깐 세워 둡니다.

마우스 포인터를 향해 짧게 뛰는 동작과 수직 점프는 서로 다른 행동입니다.
점프한 뒤에는 잠깐 주변을 보거나 쉬고 몸단장을 합니다.

6. 냥냥펀치와 화면 깨짐 장난
고양이가 앞발로 화면을 톡 치면 유리가 깨진 듯한 금이 잠깐 나타납니다.
실제 모니터나 작업 중인 파일을 바꾸지 않는 화면 연출입니다.
금은 약 3초 동안 보였다가 사라지고, 그 위에서도 아래 프로그램을 클릭할 수 있습니다.
고양이를 숨기거나 ‘이 자리에서 쉬기’를 선택하면 진행 중인 깨짐 효과도 사라집니다.

자동 냥냥펀치는 최소 12분 이상 간격을 두고 행동 후보로 선택됩니다.
고양이의 상태와 다른 행동에 따라 실제 발생 시점이 달라집니다.
바로 보고 싶다면 고양이나 알림 영역 아이콘을 오른쪽 클릭한 뒤
‘냥냥펀치 한 번 보기’를 선택하세요.

7. 실제 시간으로 성장
처음 실행한 실제 시각을 생일로 저장합니다.
하루가 지나면 하루, 1년이 지나면 1년을 함께한 것으로 계산합니다.
PC를 껐다 켜거나 한동안 실행하지 않아도 생일은 유지됩니다.
아기 고양이는 첫 실제 생일까지 크기가 아주 천천히 자랍니다.
10년을 지나도 자동으로 죽거나 초기화되지 않습니다.
먹이를 오래 못 줬다고 죽거나 사라지지 않습니다.
배고픔은 시간 단위로 천천히 변하고, 밥과 간식으로 회복됩니다.
컴퓨터 시계에 따라 나이를 계산하므로 Windows 날짜와 시간을 정확히 유지하세요.

1.4.0부터 식사 습관에 따라 체형도 천천히 변합니다.
계속 배부른 상태로 먹이면 며칠에 걸쳐 통통해지고 비만 고양이가 됩니다.
오랫동안 밥을 주지 않으면 서서히 마르고 허약해집니다.
한 번 먹였다고 갑자기 몸이 커지거나, 몇 시간 놓쳤다고 바로 앙상해지지 않습니다.
마르거나 무거워지면 걸음과 달리기, 점프 높이도 조금 줄어듭니다.
다시 규칙적으로 먹이면 적당한 체형으로 서서히 돌아옵니다.
고양이를 오른쪽 클릭해 상태를 열면 현재 체형과 포만감을 볼 수 있습니다.

배고프면 먼저 ‘집사야, 밥 조금 줄래?’처럼 짧게 말 걸기도 합니다.
말풍선은 최대 두 시간에 한 번, 고양이가 보이고 조용히 깨어 있을 때만 나타납니다.
시작 후 첫 3분, 숨김, 수면, 끌기, 메뉴·대화상자, 다른 말풍선·먹기·장난 중에는 기다립니다.
별도 팝업은 없고, 작업 중인 창의 입력을 빼앗지 않습니다.
소리를 켜 두면 말풍선과 함께 작은 야옹을 낼 수 있습니다. ‘고양이 소리’에서 끄면 조용히 표시합니다.
이전 버전에서 처음 업데이트한 고양이는 현재 생일과 돌봄 기록을 그대로 두고,
적당한 체형에서 새 식사 습관 기록을 시작합니다.

8. 오래 키우기 위한 저장
성장과 돌봄 기록은 다음 폴더에 저장합니다.
%LOCALAPPDATA%\YeopjariCat

Windows 탐색기 주소창에 위 경로를 붙여 넣으면 열립니다.
일반 저장, 이전 저장 백업, 월별 기록을 보관하며 파일 내용이 손상됐는지 확인합니다.
우클릭 메뉴의 ‘성장 기록 따로 백업하기’로 원하는 위치에도 저장할 수 있습니다.
이 메뉴는 성장과 돌봄 기록을 백업합니다.
캐릭터와 의상 선택은 같은 폴더의 preferences.ini에 따로 저장하고 백업도 유지합니다.
체형·포만감·마지막 식사와 배고픔 말풍선 시각은 nutrition.ini와 이전 백업에 따로 저장합니다.
소리 켜기·끄기와 음량은 별도 소리 설정 파일에 저장합니다.
같은 새 버전을 반복해서 알리지 않도록 update-notice.ini에 마지막으로 알린 버전을 기록합니다.
1.10.0의 친밀도·취향·성격 변화와 생활 패턴 기록은 memory.ini와 memory.bak에 따로 저장합니다.
‘성장 기록 따로 백업하기’만으로는 친밀도·의상·소리 설정까지 백업되지 않습니다.
친밀도와 모든 설정을 함께 옮기려면 고양이를 종료하고 위 저장 폴더 전체를 복사하세요.
기억 파일에 문제가 있으면 확인된 백업으로 복구합니다. 복구할 수 없으면 원본을 보존하고
기존 고양이는 계속 지내되 기억 학습을 쉬며 안내합니다.
체형 파일이 손상되면 원본을 남겨 두고 확인된 백업을 사용합니다.
쓸 수 있는 체형 기록이 없으면 생일과 성장 기록을 유지한 채 적당한 체형으로 다시 시작하고 안내합니다.
저장 기록이 손상되면 기존 생일을 조용히 새로 만들지 않도록 설계했습니다.
오래 키울수록 이 폴더를 가끔 외장 저장장치나 본인 백업 공간에 복사하세요.
PC를 바꾸거나 포맷하기 전에는 반드시 고양이를 종료하고 저장 폴더를 백업하세요.
새 PC에서는 고양이를 종료한 상태로 같은 저장 폴더에 기록을 복원하세요.
프로그램 ZIP과 실행파일만 옮기는 것으로는 현재 성장 기록이 옮겨지지 않습니다.

9. 유지와 검증
고양이를 키우는 데 인터넷 계정이나 서버는 필요 없습니다.
배포 주소가 설정돼 있고 자동 알림을 켰거나 직접 업데이트를 확인할 때에만 업데이트 서버에 연결합니다.
실행 파일은 사용자가 ‘업데이트’를 선택했을 때 내려받습니다.
성장 기록, 캐릭터 선택, 화면 내용과 키보드 입력을 서버로 전송하지 않습니다.
업데이트 서버에는 일반적인 HTTPS 요청에 따른 네트워크 접속 정보가 전달됩니다.
소스 저장소는 src/, assets/, tests/, tools/에서 앱 코드·이미지와 음원·검사·빌드 도구를 관리합니다.
배포 도구로 생성한 일반 사용자용 ZIP에는 실행에 필요한 파일과 안내만 들어 있습니다.
프로그램을 실행했다고 Windows 시작프로그램에 자동 등록하지 않습니다.

Windows x64 실행 파일은 Linux 환경에서 교차 컴파일합니다.
v1.10.0은 기존 기록 호환성과 새 친밀도·기억·10년 육성 모의 검사를 통과했습니다.
Windows x64 빌드·테스트·ZIP·업데이트 피드 검증을 통과했습니다.
실제 Windows 화면에서의 실행은 아직 확인하지 못했습니다.
작업표시줄 배치, 다중 모니터와 냥냥펀치 연출, 실제 스피커 재생과 실행 중인 파일의 교체·재시작은 Windows에서 확인이 필요합니다.
10년간의 미래 운영체제 호환성이나 디스크 고장을 보장한다는 의미는 아닙니다.

실행 후 고양이가 보이지 않으면 Ctrl+Alt+H와 알림 영역 아이콘을 확인하세요.
실행 오류가 나면 오류 문구나 화면과 사용 중인 Windows 버전을 알려 주세요.

## 1.9.0 — 성격·옷장·장난감과 더 다양한 랜덤 행동

성격은 개냥이, 시크냥, 호기심쟁이, 장난꾸러기, 잠보, 우다다냥의 여섯 타입으로 표시되며 실제 랜덤 행동 가중치에 반영됩니다. 식빵, 꾹꾹이, 빼꼼, 몸 긁기, 재채기가 추가됐고 여러 행동이 짧은 시퀀스로 이어집니다.

우클릭 메뉴의 옷장에서 빨간 리본, 포근한 목도리, 쪼꼬미 왕관을 선택할 수 있습니다. 장난감에서 공이나 박스를 꺼내면 고양이가 가끔 다가가 놀거나 박스에 들어갑니다. 기존 성장 기록과 캐릭터 선택은 그대로 이어집니다.


옆자리 고양이 1.9.1 — 동작·의상·장난감 정합성 수정

- 의상 위치가 각 자세의 머리·목과 좌우 반전, 회전, 체형, 애니메이션 전환을 따라가도록 수정했습니다.
- 식빵 자세의 바닥 잘림, 빼꼼의 갑작스러운 진입·복귀, 배 까기 회전의 바닥 침범 및 중간 종료를 수정했습니다.
- 공과 박스를 별도 클릭 통과 화면에 표시하여 고양이가 멀어져도 사라지지 않습니다. 창 위에 올라가도 장난감은 바닥에 남습니다.
- 공은 앞발이 닿는 시점부터 감속하며 굴러가고, 화면 끝에서도 다시 접근할 수 있습니다. 박스는 중심에 도착한 뒤 앉으며 고양이 체형에 맞게 폭을 조정합니다.
- 장난감 접근에는 실제 이동 거리와 감속을 사용하고 기존 체형별 이동 속도를 유지합니다.
- 움직이는 창을 매 틱 따라가며, 이동·크기 변경 중 점프 높이와 속도를 유지합니다. 이동하거나 닫힌 착지 대상도 비행 중 재확인합니다.
- 숨김·메뉴·긴 지연 중 창 사이 이동 시간도 멈춰 재개 시 순간이동하지 않도록 수정했습니다. 점프·의상·말풍선이 잘리지 않도록 창 위 여유 공간을 확보합니다.
- 이동 일시정지 후 대기 중이던 점프·걷기, 쓰다듬기 후 이전 행동 시퀀스가 재개되는 문제를 수정했습니다.
- 공중에서 요청한 밥·츄르는 착지 후 먹기 시작하며, 수동 자세나 쓰다듬기가 비행·먹기 동작을 끊지 않도록 조정했습니다.

v1.9.1 수정에서는 기존 생일·성장·체형·캐릭터·성격·의상·소리·업데이트 설정의 저장 형식과 백업·복구를 유지했습니다. 이 동작 수정만으로 필요한 저장 데이터 마이그레이션은 없습니다.


옆자리 고양이 1.10.0 — 친밀도·기억·생활 패턴

밥·츄르·쓰다듬기·장난감으로 함께한 경험이 친밀도로 천천히 쌓입니다.
상태 창에서 친밀도와 기억하는 취향을 볼 수 있습니다. 반복 클릭으로 빠르게 쌓을 수 없으며,
오래 실행하지 못해도 친밀도가 줄어들지는 않습니다. 이전 고양이는 기존 생일과 실제로
먹었던 밥·츄르 기록을 바탕으로 새 기억을 시작합니다.

쓰다듬기·츄르·놀이 습관은 이후의 반응과 행동 빈도에 반영됩니다.
친해지면 가끔 가까운 커서 쪽으로 걸어와 거리를 두고 머물고, 츄르를 좋아하게 된 고양이는
배가 고프지도, 너무 부르지도 않을 때 “그때 그 츄르… 조금만 줄래?” 하고 부탁하기도 합니다.
생일에서 시작된 기본 성격 위에 꾸준한 돌봄의 영향이 아주 천천히 더해집니다.
한 번의 돌봄이나 오랜 부재 때문에 성격이 갑자기 바뀌지는 않습니다.

Windows의 현지 시간에 따라 아침 7~10시에는 기지개를 켜고,
점심 11~14시에는 배고플 때 밥을 부탁하며, 새벽 2~5시에는 드물게 우다다를 합니다.
자거나 먹거나 숨겨져 있거나 다른 행동 중이면 기다립니다. 매번 정해진 시각에 하는 행동은 아닙니다.
‘이 자리에서 쉬기’ 중에는 다가오기나 새벽 우다다를 하지 않습니다.

오래 함께한 기간과 친밀도 조건을 채우면 다음 특별한 시퀀스가 드물게 나타납니다.
- 90일 이상, 친밀도 25 이상: 꾹꾹이 → 식빵. “네 옆이 편해졌어 ♡”
- 첫 생일 이후, 친밀도 45 이상: 꼬리 세우기 → 배 까기 → 관찰.
- 다섯 번째 생일 이후, 친밀도 65 이상: 기지개 → 꾹꾹이 → 식빵 → 잠들기.
조건을 채웠다고 바로 나타나지는 않으며, 고양이가 편안할 때 긴 간격을 두고 보여 줍니다.

새 기억은 memory.ini와 memory.bak에 저장합니다. 생일·성장·체형·캐릭터·의상·소리와
기존 자동 업데이트 설정은 이어서 사용합니다. 다른 PC로 옮기거나 포맷하기 전에는
고양이를 종료하고 %LOCALAPPDATA%\YeopjariCat 폴더 전체를 백업하세요.


포함된 이동·자세·입력 수정

- 창 위로 올라갈 때 실제 Box2D 도약·중력·발판 충돌을 사용합니다. 거리·높이와 착지 후 감속 공간을 확인하고, 도달할 수 없는 창에는 점프하지 않습니다.
- 움직이는 창은 실제 발판으로 작용합니다. 공중의 고양이 위치를 강제로 옮기지 않으며, 창이 닫히면 현재 위치와 속도에서 중력으로 내려옵니다. 창 끝에서는 미리 감속합니다.
- 배 까기는 몸 전체를 크게 회전시키는 대신 옆눕기·배 보이기 자세를 거쳐 복귀합니다. 머리가 겹치지 않도록 하나의 머리 관절을 유지합니다.
- 귀는 같은 몸 그림에서 귀 부분만 움직입니다. 꼬리 세우기·꾹꾹이·기지개·재채기의 불필요한 몸 전체 들림을 줄이고, 식빵에서 얼굴이 세로로 찌그러지지 않게 했습니다.
- 걷다가 앉거나 누울 때 먼저 감속합니다. 메뉴·숨김 뒤 보행 위상을 이어가며, 높은 점프에서 그림이 그리기 영역 밖으로 잘리지 않게 했습니다.

효과음 14개는 제공받은 영상의 네 구간으로 교체했습니다. 음소거·음량·재생 간격을 유지합니다.
기존 저장 형식과 자동 업데이트 주소를 유지하므로 기록 마이그레이션은 필요하지 않습니다.
Windows 10/11 x64용입니다. 검증 범위와 실행 결과는 저장소 docs/V1_10_3_AUDIO.md를 확인하세요.

창 위에서 우클릭이 되지 않는 이전 버전은 작업표시줄 알림 영역의 고양이 아이콘을 우클릭해 업데이트할 수 있습니다.
