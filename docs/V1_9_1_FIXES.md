# v1.9.1 동작·의상·장난감 수정

현재 공개 버전은 v1.9.0입니다. 이 수정본은 기존 기능의 동작·표시 불일치를 수정한 v1.9.1이며, 새 로드맵 기능을 구현한 v1.10.0이 아닙니다. GitHub Release에는 아직 공개하지 않았습니다.

## 확인한 문제와 수정

| 문제 | 수정 |

| 공중에서 밥을 요청하면 점프 그림과 먹는 소리가 겹침 | 요청을 일시 보관하고 착지 후 기록 갱신·먹기·소리를 시작 |
| 수동 자세·쓰다듬기가 비행/먹기 자세를 끊음 | 공중 자세 명령과 먹기 중 쓰다듬기에 상태 검사 적용 |

## 호환성과 검증

생일·성장·체형·캐릭터·의상·소리의 저장 모델과 업데이트 모듈은 v1.9.0 복원 해시와 동일합니다. 성격의 생일 파생 알고리즘도 유지합니다. 새 장난감 이동과 대기 중인 먹이 요청은 메모리 상태이며 저장 형식을 추가하지 않습니다. 데이터 마이그레이션은 없습니다. 기존 백업·손상 기록 보존·복구 검사는 계속 실행합니다.

`bash tools/check.sh`로 C++ 모델/물리/표시 좌표 검사, Python 회귀 검사, Windows x64 빌드, 실제 한국어 리소스, ZIP과 로컬 업데이트 피드의 버전·해시·구성을 검증합니다. 실물 Box2D를 연결한 접근 검사는 30/60/120Hz, 아기/성묘, 양 방향·양 끝·움직이는 공·기존 속도가 있는 경우를 포함합니다. 시퀀스 일시정지 회귀 검사는 원래 v1.9.0 코드에서 실패하는 것을 확인했습니다.

최종 실행 결과: C++ 12개 실행 파일의 검사 147,775개 통과, Python 19개 통과·1개 건너뜀, Windows x64 빌드·한글 리소스·ZIP·로컬 피드 검증 통과. 로그는 `docs/validation/v1.9.1-check.log`에 보관합니다. 최종 패키지는 `release/publish/v1.9.1-reviewed/YeopjariCat-Windows-1.9.1.zip`입니다. Python의 과거 v1.5 깨진 한글 재현 검사 하나는 해당 EXE가 없어 건너뜁니다.

이 환경은 Linux이므로 실제 Windows 화면에서 GDI+ 표시, 독립 장난감 창의 창 순서/클릭 통과, 여러 DPI 모니터, 소리 재생, 실행 중 업데이트 교체는 직접 확인하지 못했습니다. 수학/상태/물리 검사와 크로스 빌드 성공을 실화면 확인으로 표현하지 않습니다. 모든 체감상 어색함을 전부 없앴다고 보장하는 결과도 아닙니다. 이 항목들은 Windows에서 별도 실기기 확인이 필요합니다. 2026-11-04 사용자가 이 미검증 범위를 안내받은 뒤 GitHub 공개를 요청했으며, 자동 검사 결과와 실기기 미검증 범위를 릴리스 설명에도 표시합니다.

## Windows 확인 순서

1. 기존 `%LOCALAPPDATA%\YeopjariCat` 전체를 백업하고 생일·돌봄·체형·캐릭터·성격·의상·소리를 기록합니다.
2. 두 캐릭터와 세 의상을 각각 선택하고 걷기·수면·먹기·점프·배 까기·식빵·빼꼼에서 부착 위치와 바닥 잘림을 확인합니다.
3. 공·박스를 양쪽 가장자리에 놓고 접근·접촉·굴림·앉기를 확인합니다. 고양이가 멀어지거나 창 위로 올라가도 장난감이 남고 아래 앱 클릭을 막지 않아야 합니다.
4. 창 위에서 창 이동·크기 변경·닫기와 점프 중 메뉴/숨김·복귀를 확인합니다. 100/150/200% DPI와 다중 모니터에서도 반복합니다.
5. 이동 일시정지 중 자동 걷기·점프가 나오지 않는지, 점프 중 밥 요청이 착지 후 한 번 처리되는지 확인합니다.
6. 기존 저장 기록 유지와 업데이트 피드·실제 새 버전 다운로드·교체·재시작을 Windows에서 확인합니다. v1.9.0 공개 파일을 덮어쓰지 않습니다.
