# v2.0.11 — 행동 간격과 연결, 보행 충돌 수정

v2.0.10의 개별 이미지·저장·물리 검사는 통과했지만, 여러 자동 행동을 연속 실행할 때의 자연스러움까지 보장하지 못했습니다. 이번 수정은 실제 실행 흐름에서 동작이 중간에 끊기는 경로, 너무 빠른 시트 재생, 걷는 속도에서 달리기 발 순서가 선택되는 문제를 대상으로 합니다.

## 확인한 원인

- 창 방문과 장난감 선택이 자기 타이머만 보고 진행 중인 그루밍·휴식을 끊을 수 있었습니다. 일반 행동 선택 뒤 같은 틱에 생활 패턴이나 기억 이벤트가 새 행동을 시작할 수도 있었습니다.
- 그루밍은 서로 다른 16개 자세를 2.24초마다 다시 돌았고, 츄르는 90ms 간격으로 컷을 바꿨습니다. 생선 먹기 시트는 식사 행동이 끝나기 전에 이미 마무리됐습니다.
- 새 시트는 기존 관절 자세 전환을 건너뛰었습니다. 수면에서 깨어나는 시트가 끝난 직후, 같은 기상 행동 안에서 예전 기지개 그림으로 바뀌는 경로도 있었습니다.
- 창 위·장난감 접근의 걷기 속도(약 38–45px/s)가 달리기 판정 기준 35px/s를 넘었습니다. 발은 갤럽 순서를 사용하는데 몸통은 걷는 자세에 가까운 조합이 생겼습니다.

## 수정한 흐름

완료된 연속 행동과 새로 시작하는 무관한 행동을 구분합니다. 무관한 자동 행동 사이에는 18–45초의 무작위 휴식을 두고 한 틱에 하나만 시작합니다. 창·장난감·기억·생활 이벤트가 아직 끝나지 않은 동작을 덮어쓰지 않습니다. 사용자 급식·커서 반응과 창이 사라지는 물리 안전 처리는 즉시 처리합니다. 커서 놀이가 시작되면 이전 행동의 예약을 취소합니다. 두 번째 고양이도 같은 휴식 원칙을 사용합니다.

그루밍은 앞발·가슴·뒷발 중 한 흐름을 매번 무작위로 정하고 그 이벤트 동안 유지합니다. 기본 6초에서 컷을 500–750ms 이상 유지하며 모든 16컷을 빠르게 반복하지 않습니다. 사료는 고개를 숙인 씹기, 츄르는 좁은 핥기 구간만 반복하고 도입과 마무리는 한 번씩 재생합니다. 생선은 5초, 박스는 8.5초 동안 이어집니다. 수면은 3.8초 도입 뒤 대부분 웅크린 자세를 유지하며, 기상 3초 후 같은 행동 안에서 다른 기지개 그림으로 갑자기 바뀌지 않습니다.

정지한 돌봄 자세와 기존 중립 자세의 경계에는 발 기준점을 유지하는 220ms 전환과 중립 자세 연결을 사용합니다. 발이 움직이는 걷기·점프·타격·박스 소품은 전환 효과를 적용하지 않습니다. 캐릭터·크기 변경과 두 동물의 상태는 분리하며, 일시정지·늦은 첫 화면 갱신 때문에 전환이 다시 시작되는 경우도 수정합니다.

걷기·속보·빠른 달리기를 실제 속도에 맞춰 구분합니다. 중간 속도에서 갤럽이 선택되던 문제를 속보로 수정하고 몸통의 움직임도 같은 단계로 맞춥니다. 느린 걸음의 상하 움직임을 줄이며, 지지 발을 고정한 채 회수 중인 앞발은 최대 10도·뒷발은 8도로만 접습니다. 살금살금 걷기도 같은 발 접지 제어를 사용합니다.

## 호환성과 검증

저장 형식과 생일·성장·체형·선택 캐릭터·성격·기억·친밀도·두 마리 기록은 유지합니다. 새 대기·전환 상태는 실행 중에만 사용하며 저장 마이그레이션이 필요하지 않습니다. Windows 10/11 x64, Box2D 지지·중력·창 이동, 무음과 기존 자동 업데이트를 유지합니다.

로컬 전체 회귀 검사·Windows x64 교차 빌드·ZIP·업데이트 피드 검사를 통과했습니다. 마지막 보행 제동 수정은 별도 애니메이션 회귀 검사도 통과했으며, 최종 소스의 실제 Windows 검증을 진행합니다. 정식 공개는 Windows x64 빌드, 회귀 검사, 실제 Windows 실행·GDI+ 렌더링, ZIP·업데이트 피드 검증을 통과한 뒤 진행합니다.
