# 돌봄 동작 시트

사용자가 제공한 RGB PNG 9장 중 돌봄 시트 8종·104프레임을 투명 RGBA로 편집하고 기준점을 등록해 v2.0.10에 포함했습니다. 새 동작 그림은 크림냥에 적용하며 생선 급여는 고양이 8종에서 지원합니다. 실제 Windows EXE·GDI+와 패키지·공식 피드·공개 파일 검증이 통과했습니다. [동작 미리보기·검증 결과](V2_0_10.md).

## 원본과 적용 범위

원본 9장의 SHA-256과 처리 관계는 [원본 출처 기록](validation/v2.0.10-source-sprites.json)에 남깁니다. 새 그림은 크림 치즈냥에 적용하며, 첫째·둘째 고양이가 같은 클립을 사용합니다. 실버 태비와 다른 동물은 해당 캐릭터의 기존 그림을 유지합니다.

원본에는 불투명 배경이 포함되어 있습니다. 배경색의 임계값으로 알파를 추측하지 않고 이미지 편집 도구로 실제 투명 배경의 RGBA 시트를 만듭니다. 편집 결과는 원본보다 해상도가 낮고 털·얼굴·자세의 일부 픽셀이 달라질 수 있습니다. 원본을 픽셀 그대로 추출한 에셋이라는 의미는 아닙니다. 손 흔들기에 가까웠던 펀치 포즈는 두 번의 타격으로, 상자 그림은 프레임마다 같은 소품으로 이어지도록 편집합니다.

아홉 번째 걷기·뛰기 시트는 출처 기록과 참고 자료로 보존합니다. v2.0.9의 실제 이동 거리·발 접지·관절 보행을 유지하므로 이 시트를 걷기 그림으로 강제 교체하지 않습니다.

## 클립과 재생 규칙

| 클립 | 등록한 격자·프레임 수 | 재생 규칙 |
| --- | --- | --- |
| `groom` | 4×4 · 16 | 기존 랜덤 몸단장 이벤트에서 4–8초 재생 |
| `sleep` | 4×2 · 8 | 깨어 있음 0 → 하품 1 → 졸림 2 → 수면 3–7; 기상 2 → 1 → 0 |
| `box` | 4×2 · 8 | 실제 박스에 도착한 뒤 앞발·들어가기·숨기·빼꼼 순서 |
| `fish` | 4×2 · 8 | 승인된 생선 급식에서만 재생 |
| `punch` | 4×3 · 12 | 준비·두 번의 타격·회복; 기존 300/600ms 효과 시점 유지 |
| `eat` | 3×4 · 12 | 도입 0–1 → 씹기 2–8 반복 → 마무리 9–11; 기본 5초 |
| `jump` | 4×4 · 16 | 접지 웅크림 0–3, 실제 비행 5–11, 접촉 후 착지 12–15 |
| `treat` | 6×4 · 24 | 도입 0–5 → 핥기 6–14 반복 → 마무리 15–23; 기본 4.2초 |

수면 8프레임은 250/650/500ms의 도입 뒤 웅크린 잠과 깊은 잠을 중심으로 재생합니다. 꿈꾸기·수면 중 기지개·작은 움찔은 짧게 등장하며, 쉬는 동안 깨어 있는 자세와 도입 하품을 다시 반복하지 않습니다. 기상은 880ms 뒤 깨어 있는 0번을 유지합니다. 기본 수면을 고를 때 새 동작은 약 75%, 기존 다른 다섯 자세는 각각 약 5%입니다. 수면 자세는 한 이벤트에서 한 번만 고릅니다. 다른 캐릭터의 기존 선택 비율과 창 위 졸기 경로는 유지합니다.

기존 4×3·12프레임 수면 계약도 지원합니다. `Options.sheetFrames=0`은 기존 12프레임을 유지하고, 등록된 8프레임 에셋은 `sheetFrames=8`로 선택합니다. `GridAllowed()`는 수면의 4×2와 4×3을 허용하며 다른 클립의 격자는 기존과 같습니다.

점프 높이와 이동은 계속 Box2D가 결정합니다. 원본의 4번은 발이 바닥에 붙은 출발 전 자세이므로 비행에 사용하지 않습니다. 실제 비접지 상태에서는 수직 속도에 따라 5–11번을 고르며, 예상 착지 시각이 지났더라도 실제 접촉 전에는 착지 그림을 재생하지 않습니다.

## 기준점과 소품 정렬

`DrawCareSprite`는 프레임별 사각형·지지점과 클립 공통 `reference_height`를 사용합니다. 발바닥, 잠든 몸과 박스·먹이 소품에 맞는 기준점을 수동으로 등록합니다. 프레임마다 알파 경계에 맞춰 확대하지 않으므로 하품이나 고개 움직임 때문에 전체 크기가 바뀌지 않습니다. 시트를 사용할 때는 기존 추가 흔들림·전신 회전·표정 변형을 중복 적용하지 않습니다. 해당 캐릭터·클립의 시트가 없으면 기존 그림을 사용합니다.

박스 시트는 실제 장난감의 위치에 정렬하고, 도착해 멈춘 상호작용 단계에서 사용합니다. 시트가 선택되면 겹치는 기존 박스 그림을 숨기고 그 시트의 박스를 표시합니다. 시트가 있을 때만 방문 시간을 3,350ms로 늘려 들어가기·숨기기를 끝낼 수 있게 합니다. 공과 다른 장난감의 기존 물리 동작은 유지합니다.

## 생선 급식과 저장 호환성

`생선 주기`는 첫째·둘째 메뉴에서 고양이 8종에 제공합니다. 강아지·토끼에는 비활성화하고, 지연 요청 중 캐릭터를 바꾸어도 해당 제한을 다시 확인합니다. 공중에서 받은 요청은 실제 착지 뒤에 처리합니다.

생선은 기존 식사와 같은 포만감·체형 변화·배부름 거절·먹이 간 공통 5분 대기 시간·식사 횟수·기억 규칙을 사용합니다. 거절한 요청은 돌봄 횟수와 기억을 추가하지 않습니다. 생선 그림은 승인된 식사 동안만 사용하는 일시적 표시이며, 새 저장 필드가 없습니다. 생일·성장·성격·캐릭터·기억·친밀도·두 마리 기록, 기존 무음과 자동 업데이트 경로를 유지합니다.

## 등록과 검증

처리된 비인터레이스 8비트 RGBA PNG와 프레임별 `rect`·`anchor`, 공통 `reference_height`를 등록 매니페스트에 적습니다. 가져오기 도구는 PNG 바이트를 그대로 `assets/care-sprites/`에 복사하고 정규 매니페스트·C++ 목록·리소스 목록을 생성합니다.

```sh
python3 tools/import_care_sprites.py --manifest /path/to/manifest.json
python3 tools/import_care_sprites.py --check
```

`--check`는 PNG 형식·체크섬·격자·프레임·생성 파일의 일치를 읽기 전용으로 확인합니다. 등록된 RGBA 시트 8종·104프레임과 별도 빈 박스 리소스를 검사했고, 실제 Windows GDI+에서 원본 영역 104개와 체형/방향/크기 96조합의 알파·기준점·선택 경로를 확인했습니다. 시작 시 각 프레임을 독립 픽셀 버퍼와 비트맵에 복사해 인접 칸의 귀·발이 샘플링되지 않게 합니다.
