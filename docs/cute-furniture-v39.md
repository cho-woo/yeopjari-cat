# 귀여운 소품 행동 v2.0.39

버섯 캣타워를 오르내리는 8초, 선인장 스크래처를 긁고 스트레칭하는 158프레임(6.583초), 고양이 귀 박스에 들어가 쉬고 나오는 8초 동작입니다. 우클릭 행동 메뉴와 충분히 쉬는 동안의 랜덤 이벤트를 두 고양이 모두 지원합니다.

## 드롭샷 원본과 캐릭터

- `assets/furniture-v39/sources/`: Nano Banana 2.1 소품 원화 3개, MiniMax H3 Lite 크림·턱시도 원본 6편.
- `selected/prop-generations.json`, `video-generations.json`: 프롬프트, 모델, 작업 ID, 결과 URL, 원본 해시·프레임 정보.
- `references/`, `selected/reference-registration.json`: v37 불변 크림·턱시도 원화를 같은 1024/367 크기로 합성한 시작·끝 조건. 시작과 마지막은 같은 오른쪽 방향의 원화입니다.
- 눈꽃냥은 승인된 흰 털·금색/파란색 홍채 재질을 크림 영상에 적용합니다. 원본의 자세·알파·피부색과 차가운 색 소품을 유지합니다. `selected/review/`에 선택 프레임과 눈 추적 기록을 보관합니다.
- `manifest.json`: 전체 원본 프레임 목록, 해시, 9개 런타임 파일과 공통 기준점. 임의 구간 반복이나 프레임 생략 없이 모두 사용합니다.

## 앱 연결

새 `furniture::Session`이 대기 → 안전한 자리로 걷기 → 오른쪽을 향해 준비 → 전체 영상 → 750ms 회복을 소유합니다. 원본 속 소품과 고양이가 하나의 RGBA 장면이므로 앞발 접촉, 발판 위 체중 이동, 박스 벽의 가림이 한 좌표와 시간에 맞습니다. 장면 동안 물리 루트는 고정하고 영상 속 이동을 그립니다. 별도의 순간이동이나 상자 진입 좌표 재설정은 없습니다.

오른쪽 여백이 부족하면 기존 걷기·제동·발 짚는 턴을 통해 이동하고 시작합니다. 성장·몸 너비를 여백 계산에 적용합니다. 캔버스만 넓혀 소품을 표시하고, 창 위치와 물리 바닥은 계속 같은 세계 좌표를 사용합니다. 앞뒤는 동일 기준점으로 교차 표시하고 소품을 몸으로 변형하는 보간은 사용하지 않습니다.

영상은 로컬 리소스로 포함됩니다. Windows Media Foundation을 동적으로 불러와 별도 작업 스레드에서 현재 행동 하나만 미리 해독하며, 재생 경로는 해독·탐색을 하지 않습니다. 고양이마다 현재 영상 하나만 유지하고 끝나면 해제합니다. 미디어 기능이 없는 Windows에서는 해당 행동을 취소하고 나머지 앱을 유지합니다. 동영상에 음성 트랙은 없습니다.

자동 이벤트는 사용 가능한 조용한 바닥 시간만 셉니다. 첫 대기는 90~180초, 완료 후 다음 대기는 180~420초입니다. 메뉴·다른 행동·이동 중지 시간에는 누적하지 않습니다. 명령은 진행 중인 행동을 자르지 않고 안전한 경계에서 시작합니다. 영상과 복귀가 끝날 때까지 포인터·자동 행동·돌봄·드래그·외형 변경이 끼어들지 않습니다.

## 검증과 재현

- `tests/cat_furniture_test.cpp`: 9개 전체 동작, 안전한 접근, 해독/준비 게이트, 일시정지·긴 정지, 끝까지의 회복과 이벤트 간격.
- `tests/furniture_registration_test.py`: 원본·런타임·불변 참조 해시, 동일 첫/끝 조건, 모든 프레임과 공통 크기 보존.
- `--furniture-review COAT ACTOR KIND SCENARIO FILM`: 앱의 실제 명령·모터·Box2D·표시 자세·Windows 해독기·GDI+ 렌더러를 사용합니다. COAT=0/8/10, ACTOR=0/1, KIND=1/2/3, SCENARIO=0(기본)/1(오른쪽 끝)/2(성장·150% 배율·일시정지). 정상 조건 FILM=1은 연속 30FPS PNG, 그 외 FILM=0은 정지 표본을 보관합니다.
- 각 경로는 원본 전체 프레임 표시, 행동·회복 완료, 재생 중 물리 루트 변화, 비의도적 위치 단절, 저장 기록 미변경을 검사하고 CSV·JSON을 남깁니다. 바탕화면 녹화가 아닌 배포 앱 렌더러 출력입니다.
- 최종 검사는 CI가 포장한 동일 EXE로 수행한 뒤 그 파일을 배포합니다. 기존 v2.0.38의 128MiB 업데이트 상한을 유지합니다. 현재 설치 파일의 미서명 게시자 안내도 유지합니다.
