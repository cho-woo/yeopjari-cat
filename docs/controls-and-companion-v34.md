# v2.0.34 포인터·키보드와 두 고양이 놀이

빠른 근거리 왕복은 앞발 행동으로 유지하고, 멀어지는 포인터에는 다음 발 디딤에서 추격을 시작한다. 방향 입력의 작은 흔들림이 몸 전체의 턴이나 점프 준비를 반복해서 취소하던 문제를 고쳤다. 원인 재현은 [v33 진단](cursor-jitter-diagnosis-v33.md)에 남겼다.

## 영상과 적용

Dropshot MiniMax H3에서 canonical first/last image를 지정한 4초·768p 영상 12개를 생성했다. 10개를 채택하고 두 개의 합본 걷기 경계 영상은 끝 방향이 맞지 않아 제외했다. 새 걷기 시작/마무리는 각각 따로 생성했다. 생성 비용은 1,920 credits이며 완료 후 잔액은 10,805다.

- 원본 12개: `assets/video-actions/sources/controls-v34/`
- 작업 ID·전체 생성 인자·해시·채택 여부: `assets/video-actions/generation.json`
- 원화 배율·선택 프레임·발 접촉·종료 지점·구간 사이 발 위상: `identity-v29.json`, `registration.json`, `provenance.json`
- 이전 등록: `assets/video-actions/history/v33/`

새 펀치는 107장의 연속 원본 프레임 전체를 사용한다. 포인터가 빠져나갈 때 현재 타격의 발이 실제로 바닥에 내려온 프레임까지 재생한다. 새 턴은 원본 4~45번의 연속 42장으로 제동·발을 짚은 회전·반대 방향 출발을 모두 포함한다. 반복 걸음은 기존의 연속 157장, 달리기는 106장을 보존했다. 가감속 24장씩, 걷기 시작/마무리 36장씩을 별도의 구간으로 연결했다.

얼굴이나 몸을 매 프레임 높이로 재정규화하지 않는다. 367px 원화 기준과 고정된 좌우 기준점, 발바닥과 실제 물리 바닥을 공유한다. 오드아이는 같은 Cream 원본과 기존 재질 처리를 사용한다. 출구 자세와 반복 걸음은 발에 가중치를 둔 같은 배율의 그림 비교로 위상을 맞췄다.

## 입력과 두 번째 고양이

근처 포인터는 70px 이내에서 앞발 반응을 시작해 120px 밖으로 나갈 때까지 유지한다. 실제로 가만히 둔 포인터의 부드러운 높이 뻗기와 움직이는 포인터의 연속 타격은 각 영상의 완전한 시계를 유지한다. 멀리 있는 포인터가 반대로 가려면 140ms 동안 방향이 유지돼야 몸을 돌린다.

키보드의 Shift는 이동 주체를 다시 만들지 않는다. 진행 중인 턴·가감속 영상을 보존하고 최신 방향과 점프 요청을 다음 안전한 시점에 적용한다. 짧은 키 입력은 아직 진행 중인 시작/종료 영상의 같은 프레임에서 되돌아간다. 방향 전환 시 오래된 목표 쪽으로 가속하던 모터 계산도 수정했다.

두 번째 고양이는 같은 `CursorSession`과 Dropshot 프로그램을 사용하며 몸·시계·접촉·기억은 각각 소유한다. 포인터 반응, 실제 물리 추격·도약, 파리 사냥, 앞발·공·낚싯대 놀이, 그루밍, 꾹꾹이, 낮잠, 이동·점프·오르기와 키보드 조종을 자신의 메뉴에서 실행할 수 있다. 공은 두 번째 고양이의 별도 Box2D 물체와 발 접촉으로 움직인다. 기존 밥·츄르·생선의 수락과 기록 경로는 유지한다.

두 마리가 가까워지면 서로 마주 보고 새 앞발 영상 한 차례를 끝까지 재생하고 900ms 쉬었다가 다시 장난친다. 서로 장난친 기록은 이벤트당 한 번이며 사람의 돌봄·식사·놀이 보상을 만들지 않는다. 기존 자동 행동 경계·사회 행동 간격을 유지해 다른 행동 사이에 끼워 넣지 않는다. 사용자는 두 번째 고양이 메뉴에서 직접 함께 놀게 할 수도 있다.

턱시도와 오드아이를 함께 띄워 Cream 재질을 해제한 상태에서도, 각자의 상주 그림으로 애니메이션을 선택하도록 수정했다. 기존에는 공통 원본 재질의 존재만 확인해 두 외형의 영상 적용이 빠질 수 있었다.

## 재현과 검증

- 근거리 독립 포인터: 세 외형 × 두 진폭 × 세 높이 × 두 왕복 주파수, 각 20초. 몸 턴·거울 반전·뜬금없는 점프와 루트 이동을 검사한다.
- 탈출 포인터: 타격의 서로 다른 네 시점에서 포인터가 멀어질 때 등록된 발 디딤 종료를 확인한다.
- 키보드: 걷기/달리기/반전/턴 중 Shift 변경/정지/빠른 Shift/짧은 탭/점프를 20초 연속 입력한다. 이동 주체 재시작, 잘린 턴, 역행하는 시계를 검사한다.
- 두 번째 고양이: 세 외형의 20초 왕복·원거리 추격과 도약, 각 행동의 실제 프로그램 진행, 키보드·물리 행동을 검사한다.
- 두 마리: 아홉 외형 조합에서 두 차례 완전한 앞발 동작과 회복, 이벤트 중복 보상·식사 기록 오염 여부를 검사한다.
- Windows 실제 렌더러: `--render-controls-video`는 28초·60FPS 입력 영상, 12초·30FPS 두 고양이 영상과 세 외형의 두 번째 고양이 사냥 그림을 출력한다. `--render-self-test`에도 포함돼 CI의 정확한 배포 실행 파일로 실행한다.

검증 입력은 메모리 안에서 공급한다. OS 입력을 주입하거나 사용자의 실행 중인 고양이와 저장 파일을 조작하지 않는다. 영상은 실제 앱 GDI+·Box2D 경로의 출력이며 바탕화면 녹화는 아니다. 원본/앱 비교, 해시와 검사 보고서는 릴리스 검증 자료로 제공한다.
