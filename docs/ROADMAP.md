# 개발 로드맵

현재 정식 버전은 **v1.9.0**입니다. 이번 구조 정리에는 새 기능·버전 변경·Release 공개가 없습니다.

| 버전 | 예정 기능 |
| --- | --- |
| v1.10.0 | 친밀도, 사용자 행동 기억, 시간대별 생활 패턴, 돌봄에 따른 매우 느린 성격 변화, 장기 육성 희귀 행동 해금 |
| v1.11.0 | 커서 사냥·관찰·추적·냥냥펀치, 창 사이 거리·높이 기반 점프, 움직이는 창에서 균형, 닫힌 창에서 놀라 내려오기, 희귀 행동 확대 |
| v1.12.0 | 의상 확대, 캣닢·낚싯대·쿠션, 계절·생일·함께한 기간 기념 이벤트 |
| v2.0.0 | 두 마리 동시 육성, 냄새 맡기·함께 뛰기·펀치·함께 자기·먹이 경쟁·창 위 따라가기, 개별 성격·친밀도·성장 |

기존 모델의 `affection` 값과 시간대/커서 컨텍스트는 이미 존재하지만 로드맵 기능이 완성되었다는 뜻은 아닙니다. 각 버전은 기존 기능·Box2D·업데이트·사용자 기록을 유지하고, 필요한 자동 마이그레이션과 회귀 검사 후 배포합니다. 빌드·테스트·ZIP·피드 검증이 실패하면 배포하지 않습니다.
