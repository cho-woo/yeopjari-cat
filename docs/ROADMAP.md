첫 번째 동물은 기존 생일·성장·체형·성격·기억을 이어갑니다. 두 번째 동물은 사용자가 선택할 때 별도 기록으로 생성됩니다. 예전 한 마리의 기록을 복제하거나 초기화하지 않습니다.

남은 작업은 정지↔보행의 그림 교체와 방향 반전, 배 까기 전환의 이미지 혼합과 이륙·공중 자세의 별도 그림을 더 정교한 관절 애니메이션으로 연결하기, 두 번째 동물의 특별 희귀 시퀀스·기념일·식사 요청 반응 확대, 선택형 실제 날씨 연동입니다. 현재 모든 동작이 하나의 관절 모델로 이어지는 것은 아닙니다. 두 번째 동물에도 시간대별 행동 비중·숨은 기분·계절 의상은 적용됩니다. Windows 10/11의 다양한 모니터·창 환경 수동 검수도 자동 CI와 구분해 이어갑니다.

사용자 요청에 따른 소리·수동 조작 제거를 반영하면서 Box2D·자동 업데이트·사용자 기록을 유지합니다. 친밀도는 오랫동안 PC를 켜지 않았다는 이유로 사라지지 않으며, 돌봄에 따른 성격 변화는 느리게 제한합니다. 빌드·테스트·Windows 실행·ZIP·피드 검증이 실패하면 공개하지 않습니다.
