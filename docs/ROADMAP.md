# 개발 로드맵

현재 공개 정식 Release는 **v1.9.0**입니다. 소스에는 v1.9.1의 모션·의상·장난감·창 발판 수정과 **v1.10.0**의 친밀도·기억·생활 패턴이 구현되어 있습니다. 배포 여부는 GitHub Releases에서 확인합니다.

| 버전 | 범위와 상태 |
| --- | --- |
| v1.10.0 | 구현: 친밀도, 밥·츄르·쓰다듬기·놀이 기억, 아침/점심/오후/밤/새벽 패턴, 매우 느린 성격 보정, 90일·1년·5년 희귀 행동 시퀀스. [설계·검증](V1_10_0.md) |
| v1.11.0 | 예정: 커서 관찰·사냥·앞발 잡기, 빠른 커서 포기·정지 커서 냄새 맡기·가끔 위에 앉기, 업무 방해 모드 ON/OFF. 창 사이 거리·높이와 착지 여유 계산, 아래 보기·너무 먼 점프 포기, 움직이는 창의 균형 자세, 닫힌 창에서 놀라 내려오기. |
| v1.12.0 | 예정: 의상 확대, 캣닢·낚싯대·쿠션, 선택형 날씨·계절 반응, 겨울 목도리 추천, 산타·호박·생일모자, 함께한 기간 기념 이벤트. |
| v2.0.0 | 예정: 두 마리 동시 육성, 냄새 맡기·함께 뛰기·펀치·함께 자기·먹이 경쟁·창 위 따라가기. 고양이별 성격·친밀도·성장·기억을 분리하고 기존 한 마리 기록을 자동 이전. |

v1.11 이후 희귀 행동 후보는 화면 금 장난 뒤 놀라 도망가기, 창 끝에서 매달리기, 재채기에 놀라기, 작은 박스에서 삐져나오기, 왕관을 쓰고 우쭐하기, 화면 반대편 재등장입니다. 기존 냥냥펀치·재채기·박스를 없애거나 희귀 행동으로 제한하지 않습니다.

수면 자세 확대(식빵잠·옆잠·배 보이기·얼굴 묻기·꼬리로 얼굴 가리기·창 위에서 졸기)는 별도 그림과 의상 부착 검증을 포함해 진행합니다. 품종 확대(검은냥·삼색이·치즈냥·샴·턱시도·브리티시 숏헤어·먼치킨)는 스킨뿐 아니라 움직임·울음·먹이 성향 차이를 설계한 뒤 버전을 정합니다. 새 품종으로 바꿔도 기존 생일·성장 기록은 유지해야 합니다.

각 버전은 기존 기능·Box2D·자동 업데이트·사용자 기록을 유지합니다. 친밀도는 오랫동안 PC를 켜지 않았다는 이유로 사라지지 않으며, 돌봄 습관에 따른 성격 변화는 타고난 성격을 바탕으로 수개월에 걸쳐 제한적으로 적용합니다. 빌드·테스트·ZIP·피드 검증이 실패하면 공개하지 않습니다. 실제 Windows 표시·입력·소리·업데이트 교체 검증 여부도 배포 기록에 구분해 적습니다.
