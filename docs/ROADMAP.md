첫 번째 동물은 기존 생일·성장·체형·성격·기억을 이어갑니다. 두 번째 동물은 사용자가 선택할 때 별도 기록으로 생성됩니다. 예전 한 마리의 기록을 복제하거나 초기화하지 않습니다.

남은 작업은 배 까기 몸통의 짧은 그림 혼합을 더 정교한 관절 애니메이션으로 개선하기, 두 번째 동물의 특별 희귀 시퀀스·기념일·식사 요청 반응 확대, 선택형 실제 날씨 연동입니다. 현재 두 번째 동물에도 시간대별 행동 비중·숨은 기분·계절 의상은 적용됩니다. Windows 10/11의 다양한 모니터·창·스피커 환경 수동 검수도 자동 CI와 구분해 이어갑니다.

각 버전은 기존 기능·Box2D·자동 업데이트·사용자 기록을 유지합니다. 친밀도는 오랫동안 PC를 켜지 않았다는 이유로 사라지지 않으며, 돌봄에 따른 성격 변화는 느리게 제한합니다. 빌드·테스트·Windows 실행·ZIP·피드 검증이 실패하면 공개하지 않습니다.
