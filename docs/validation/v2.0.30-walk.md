# v2.0.30 source-video walk repair

The previous walk used twenty resampled drawings from a non-cyclic part of a combined stand/walk/sit movie. Its endpoints changed the head angle and paw phase. A per-frame lower-body bounding-box median also changed the artwork origin as different legs entered the sample band. Source-video generation alone did not validate the resulting application loop.

Six new Dropshot MiniMax H3 Lite jobs retain the exact canonical first and last reference images: one continuous walk, one front-to-side entry and one side-to-front recovery for each coat. Original movies, generation IDs, prompts, credits, selections and hashes remain in assets/video-actions. The complete six-second walk is retained at source cadence; only its duplicated final endpoint is omitted, making 157 loop drawings. Entry and recovery use separate videos (56 and 32 drawings). Every registered drawing identifies its original file and source frame.

The walk uses one fixed horizontal scene origin per coat, with each painted sole registered to the physical ground and the shared original character scale. No per-frame body-width median shifts the horizontal origin, and no per-frame size normalization changes its proportions. Contact-paw optical flow in the floor band measures about 30.67 logical px/s for Cream and 33.71 for Tuxedo. The pooled 212 px complete-movie stride keeps root translation synchronized with source cadence. The original camera-space foot movement is preserved, without synthesizing or warping poses.

Native validation uses the shipping dispatcher, ground bridge, Box2D, frame selector and GDI+ renderer. Its extended walking capture covers the entire source loop twice, physical braking/rest and a separate reverse walking command. Running, care and interaction checks remain part of the full Windows suite. Preview output is an offscreen application capture, not a desktop recording.

Local validation passed: Python105 tests (five environment-specific skips), companion/pacing/random-run/cursor host models, native whole-walk capture, full render suite, manual commands and jump continuity, meal/walk/run capture, ball play and native cursor host. The seam regression rejects both old coats (boundary changes 2.11/1.56 times average adjacent change); the new boundaries measure0.78/0.40. Final packaging also runs the separate Linux and Windows CI suites.
