# v2.0.27 개발 검증

이번 변경은 이동 중 점프, 앞에 보이는 창 선택, 초싸이언 모드 제거다.
현재 점프 그림은 기존 원화다. 새 영상 기반 점프·입 닦기·양앞발 들기·꾹꾹이·냥냥펀치 원화는 아직 생성하거나 적용하지 않았다.

- `cat_running_jump.hpp`는 실제 지상 속도와 이전 이동을 보관한다. 준비 120ms 동안 이동을 유지하고, `JumpWithMomentum`은 Box2D의 실제 수평 속도에 공중 모터를 더하지 않는다. 착지 후 같은 방향의 보행을 이어간다. 주인공과 동반 고양이가 이 구조를 공유한다.
- `FrontApplicationWindow`는 현재 모니터의 실제 Z 순서를 사용한다. 앞 창의 높이·크기가 부적합해도 뒤 창을 고르지 않는다. 준비·비행·창 위 체류·동반 고양이의 지지 창도 같은 조건을 사용한다. 가려진 지지는 제거하며 위치를 새 창으로 재설정하지 않는다.
- 초싸이언 메뉴·오라용 표면·속도/높이 배율·X 입력·Ctrl+Alt+S 등록을 제거했다. 이전 명령 2305와 핫키 0x2602는 새 기능으로 재사용하지 않는다.

## 현재 확인한 범위

`bash tools/check.sh`가 통과했다. Python 104건 중 이전 버전 실행파일 fixture 1건은 기존 조건에 따라 건너뛰었다. Box2D 이동 점프 검사는 30/60/120Hz, 양방향 보행/달리기 속도에서 3,172개 조건을 통과했다. 동반 고양이의 실제 자율 행동·이륙·속도 유지 검사도 통과했다.

Windows x64 교차 빌드와 한국어 대화상자 리소스 검사를 통과했다. 실행파일은 `release/YeopjariCat.exe`다. [최종 Windows 실행 검사](https://github.com/cho-woo/yeopjari-cat/actions/runs/42947178499)는 소스 `31beeb4c9c3fb94871ab9c0288b54915cf30da2b`에서 두 작업 모두 성공했다. 실제 HWND 앞뒤 순서·창 가려짐/소멸·물리 착지, 세 캐릭터의 키보드 보행/달리기 점프, 기존 돌봄·커서·공놀이·메뉴 표시와 기록 회귀 검사를 수행했다. 100% CI 화면에서의 실행이며, 사용자 바탕화면 녹화나 배율이 다른 실제 듀얼 모니터 검증은 아니다.

`native_keyboard_play_tests.hpp`와 manual-motion 검사는 방향키를 유지한 보행/달리기 점프, 공중 속도 유지와 착지 후 보행을 실제 제품 경로에서 검사한다. `jump-continuity`의 `walk-stop-jump`는 **명시적으로 정지한 다음 제자리 점프하는 별도 시나리오**다. 이동 점프 영상으로 소개하지 않는다.

## 수정 중 확인하고 해결한 연결 문제

착지 후 `SetMotion`이 수동 조종 상태를 잠깐 해제하면, 이동 쉬기 설정이 켜진 키보드 조종에서 보행 연결에 정지 대기가 걸렸다. 실제 착지의 기존 조종 소유권을 자세 선택 전에 이어주도록 수정했다. 세 캐릭터 모두 보행 점프 약 69.36px, 달리기 점프 약 147.69px를 전진하고 이동을 이어가는 Windows 검사가 통과했다.

이륙 시 `Jump`가 물리 보간의 이전 X까지 현재 X로 바꾸는 경로도 수정했다. 이동 점프에서는 기존 수평 보간 위치와 보행 누적 거리를 유지한다. 네 속도와 다섯 보간 시점에서 이륙 전후 표시 X가 바뀌지 않는 검사를 추가했다.

20초 미리보기는 고정 지면 위에서 보행/달리기 점프를 각각 10초 출력한다. 앱과 같은 요청·물리·자세 선택·GDI+ 그리기를 사용하고, 60Hz 시뮬레이션에서 30FPS로 600장을 표본화했다. 합성 원화나 이전 버전 바탕화면 녹화가 아니다. 현재 점프 그림의 측면/사선 시점 차이는 남아 있으며 새 영상 기반 원화가 필요하다.

성능 자료는 동일한 Windows 4논리 CPU·96DPI 환경에서 **v2.0.15와 v2.0.27**을 비교한 기존 기준선이다. v2.0.26과의 직접 비교로 소개하지 않는다. 이번 v2.0.27 표본의 시작 시간 약 1.072초, 평상시 PrivateUsage 약 304MiB, 기계 전체 CPU 기준 대기 약 0.048%·활동 약 0.032%·반복 전환 약 0.273%였다. 여섯 번 전환 후 증가량은 0이었고 정리 구간에서 약 28KiB 감소했다. 짧은 표본의 관측이며 장시간 누수가 없다는 증명은 아니다.

## 영상 제작 대기

드롭샷 네트워크 허용 변경은 실행 환경에 적용됐다. 실제 MCP 초기화 요청에는 `401 An Authorization Bearer token is required`가 반환됐다. [공식 안내](https://aistudio.dropshot.io/mcp)는 별도 API 키 없이 MCP 계정 로그인을 사용한다고 명시한다. 설치된 플러그인의 도구는 현재 작업의 도구 목록에 나타나지 않았다. 인증 우회나 임의의 모델 API 호출은 하지 않았다.

`python3 tools/prepare_dropshot_motion_refs.py`는 현재 등록된 크림치즈냥 그림에서 정면·측면 참조 PNG와 여섯 장면의 제작 요청서를 `build/dropshot/reference/`에 출력한다. 카메라와 지면을 고정하고 기존 얼굴과 무늬를 보존하도록 요청한다. 이 파일들은 원화 추출과 제작 입력이며 생성된 동영상이나 새 중간 원화가 아니다. 현재 생성 영상 0개, 추가 원화 0장이다.

드롭샷 연결 후 실제 Seedance 2.5 카탈로그의 업로드·길이·모델 설정을 읽고 생성해야 한다. 출력 영상의 이동·높이를 그대로 Box2D 위에 더하지 않고, 원본 루트와 접지 기준을 추적해 실제 비행 상태에 자세를 연결한다. 턱시도·오드아이는 기존 공통 동작/털색 등록을 유지한다.

## 공개 배포

v2.0.27을 검증한 초안의 동일한 43개 파일로 공개했다. 공식 최신 피드와 모든 공개 다운로드의 해시를 비인증 HTTPS로 확인했고, 공개 실행파일을 `release/YeopjariCat.exe`에 복사했다. 자세한 출처와 해시는 [공개 검증 기록](v2.0.27-published.json)에 있다. 자동 승격 재실행에서 미리보기 재인코딩 바이트가 달라져 업로드를 멈췄으므로, 이미 검증한 초안 파일을 그대로 승격했다. 기존 파일의 덮어쓰기나 재인코딩은 하지 않았다.
