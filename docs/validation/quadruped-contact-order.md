# 보행 접지 순서와 그림 비율 검토

검토 대상은 v2.0.7의 `cat_gait.hpp`와 크림 원본 걷기 그림이다. 숫자 검사는 보행·접지의 조건을 확인하며, 그림이 자연스럽다는 판정을 대신하지 않는다.

## 현재 단계의 원인 구분

크림·실버의 일반 Walk는 원본 그림 네 장을 교체하고 `Cycle::Targets()`의 네 발을 실제로 그리지 않는다. 따라서 아래 순서를 수정하는 것만으로 현재 일반 걷기의 발 미끄러짐이나 들리지 않는 뒷발을 고칠 수 없다. 독립된 발이 지지 중에는 화면상의 같은 지점을 버티고, 이동 단계에는 바닥에서 실제로 떨어져 돌아오는 렌더링이 필요하다.

## 느린 사족보행의 순서

현재 발 인덱스는 0=가까운 뒷발, 1=먼 뒷발, 2=가까운 앞발, 3=먼 앞발이다. 느린 보행의 위상 오프셋은 각각 `.25, .75, 0, .5`다. 위상은 증가하고 접지는 각 발 위상이 1에서 0으로 돌아올 때 시작하므로, 순서는 다음과 같다.

**가까운 뒷발 → 가까운 앞발 → 먼 뒷발 → 먼 앞발 → 반복**

이것은 같은 쪽 뒷발 다음 앞발을 디디는 lateral-sequence walk다. 좌우 앞발끼리와 좌우 뒷발끼리는 반 주기 차이다. 현재 느린 보행은 이미 이 순서를 충족한다. 빠른 속도에서 대각선 두 발의 타이밍을 가깝게 만드는 변화도 별도로 있다. 일반 걷기의 위상 숫자를 다시 바꾸는 것이 이번 수정의 우선순위는 아니다.

22 body px/s, 보폭 24 px, 접지 비율 .68의 안정된 주기에서 다음 값을 얻었다.

| 항목 | 값 |
| --- | --- |
| 한 주기 | 1.091초 |
| 다음 발이 착지할 때까지 | 약 .273초 |
| 한 발의 접지 시간 | 약 .742초 |
| 한 발의 이동 시간 | 약 .349초 |
| 3개 발이 지지하는 비율 | 이상적 위상 기준 72% |
| 2개 발이 지지하는 비율 | 이상적 위상 기준 28% |
| 공중에 모든 발이 뜨는 구간 | 없음 |

실제 `Cycle`을 240Hz로 8초 구동하고 초기 2초를 제외했다. 접지 발의 `rootX + foot.x`는 동일 contact ID 동안 최대 `2.85e-14` px 변했다. 접지한 발은 요청 속도가 아닌 실제 root 이동만큼 뒤로 움직이는 조건이 맞다. 표본 지지 수는 3발 1,039개, 2발 402개였다. 이 결과는 원본 그림 네 장의 화면상 발이 고정되었다는 의미가 아니다.

## 짧은 다리 그림에 적용할 범위

기존 크림 frame 1은 381×339이며 공통 배율은 `110/367`이다. 기존 분리 마스크의 각 발바닥 마지막 6행에서 알파 가중 중심을 측정하면 가까운 뒷발→앞발 사이가 약56 body px, 먼 뒷발→앞발 사이는 약13.5px다. 이것은 실제 관절 좌표가 아니라 원근이 강하게 들어간 원본 그림의 발바닥 위치다. 모든 발을 동일한 시상면에 놓인 긴 몸통의 고양이처럼 취급해서는 안 된다.

고양이가 뒷발을 이전 앞발 자국 부근에 놓는 direct register를 강제로 맞추려면, 같은 쪽 앞발과 뒷발의 투영 간격 S와 접지 시점 차이를 함께 맞춰야 한다. 현재 순서에서는 이전 앞발 접지에서 같은 쪽 뒷발 접지까지 약3/4주기가 지난다. 발별 중립 위치 차이가 없으면 `S ≈ .75 × stride`가 필요하다. 가까운 쪽 그림의56px를 그대로 쓸 경우 보폭 약75px가 필요해, 짧은 다리에 맞지 않는다. 기존 +3/-4px 중립 보정까지 적용해도 필요한 보폭은 약65px다. 반면 먼 쪽은 훨씬 작은 보폭을 요구한다.

이번 보행에서는 직접 발자국 겹침을 강요하기보다 다음을 우선한다.

- 같은 쪽 뒷발 다음 앞발을 옮기고, 반대쪽 다리는 반 주기 차이를 유지한다.
- 디딘 발은 실제 바닥의 같은 지점을 유지한다. 들어 올린 발만 작은 곡선으로 앞으로 회수한다.
- 몸의 고정점을 중심으로 위·아래 다리가 굽고 발 전체는 함께 이동한다. 발 그림을 길게 늘여 목표점에 맞추지 않는다.
- 원본처럼 짧은 다리에서는 느린 걷기 보폭18–20px부터 검토한다. duty .68에서 접지 전후 반폭은6.12–6.8px로, 기존24px의8.16px보다 과도한 앞뻗음과 뒷벌어짐을 줄일 수 있다. 최종 보폭은 실제 관절 길이와 그림 검토로 결정한다.
- 새 관절식 렌더러의 중립 위치는 어깨·엉덩이와 발의 관계에서 정한다. 기존 `NeutralX(+3,-4)`는 기존 분리 그림의 이미 뻗은 자세를 보정한 값이므로 무조건 재사용하지 않는다.

머리 크기·모양을 고정하는 것, 네 발이 수학적으로 접지하는 것, 눈으로 본 몸과 다리 연결이 자연스러운 것은 각각 별도로 확인해야 한다.

## 이번 관절 후보의 설정과 검사

새 후보에는 보폭18px, duty .72, 발 들기2.6px의 별도 고정 보행 주기를 적용한다. 느린 걸음에서 이전 그림의 +3/-4px 중립 보정을 적용하지 않는다. 22px/s에서 한 주기 약 .818초, 다음 발 접지까지 약 .205초, 한 발 접지 약 .589초·회수 약 .229초다. 이상적 위상에서 88%는 3발, 12%는 2발이 지지하며, 접지 구간의 반폭은6.48px다.

`tests/cat_articulated_walk_test.cpp`는 이 주기로 실제 IK가 푼 발바닥 좌표를 world 좌표로 환산해 접지 중 위치가 유지되는지 확인한다. 위·아래 뼈 길이, 앞다리와 뒷다리의 서로 다른 굽힘 방향, 도달 목표의 잘못된 보정 여부도 확인한다. 합성 무늬를 입힌 지원 비율의 고양이 형태로 머리 픽셀 유지, 발바닥과 관절 연결 경로의 실제 알파, 출력 경계·알파 형식을 검사한다. 이는 숫자상 발바닥만 움직이고 실제 스킨은 누락되는 오류를 잡기 위한 검사다. 실제 크림·실버 PNG의 모양·털 연결과 전체 동작의 자연스러움은 별도 시각 검토와 Windows 렌더 검사가 필요하다.
