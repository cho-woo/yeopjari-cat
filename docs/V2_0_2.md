## 커서 사냥

첫 번째 동물의 커서 놀이를 보강합니다. ‘업무 방해 모드 · 커서와 놀기’를 켠 동안 가까이 움직이는 커서에 앞발로 빠르게 톡 치도록 반응합니다. 근처에서 계속 움직여 놀리면 강한 냥냥펀치 → 짧은 추격 → 웅크림 → 목표점을 정한 실제 도약으로 이어질 수 있습니다. 가만히 둔 낮은 커서에 다가가 냄새를 맡거나 가볍게 톡 치고, 드물게 잠깐 앉는 기존 반응도 유지합니다. 두 번째 동물의 별도 커서 사냥은 이번 변경에 추가하지 않습니다.

도약은 Box2D의 속도·중력·착지를 사용하고 거리·높이·현재 지지면과 도달 가능성을 확인합니다. 커서 위치로 동물을 순간 이동시키거나 사용자의 포인터를 옮기지 않습니다. 너무 빠르거나 멀어진 커서는 포기하며 모든 접근에 반드시 도약하는 것은 아닙니다.

이미 뛰어오른 뒤 옵션을 끄거나 커서가 멀어지면 추가 추적·접촉 보상을 중단합니다. 이미 가한 도약은 실제 착지까지 이어지고 공중에서 새 커서 위치로 방향을 바꾸지 않습니다.

업무 방해 모드는 기본 OFF이고 기존 선택을 유지합니다. 숨김·메뉴·드래그·휴식·옵션 해제 상태에서는 새 커서 놀이를 시작하지 않습니다. 일반 작업표시줄 산책과 자동 창 방문은 업무 방해 모드와 별개로 계속됩니다.

## 이동과 자세 연결

첫 번째와 두 번째 동물의 `Walk`·`Stalk`·`Zoomies`는 하나의 기본 보행 그림에서 보이는 다리를 분리해 연속적으로 움직입니다. 보행 주기 동안 얼굴·몸통 그림과 크기를 유지하고, 실제 지지면에 대한 상대 이동 거리로 다리 동작을 진행합니다. 움직이는 창에 실려 간 거리는 보행 거리에서 제외합니다.

짧은 다리에 맞춰 한 주기 이동 거리를 몸 기준 걷기 28·살금살금 24·우다다 38픽셀로 정합니다. 실제 성장 크기는 반영하되 영양 상태에 따른 몸 너비 변화로 물리 보폭까지 늘리지 않습니다. 다리와 몸통의 연결 부위를 겹치고 원본 그림 주변에 여유를 두어, 움직일 때 연결부에 틈이 벌어지거나 발이 잘리는 것을 막도록 구성합니다.

세로 물리 위치를 정수로 반올림하면서 버리던 소수점 차이를 그림 안의 위치에 반영합니다. 느린 상승·하강이 한 픽셀씩 튀는 현상을 줄이고, 몸 위치와 발걸음 거리에도 같은 물리 보간 시점을 사용합니다. 120Hz 등 물리 계산보다 자주 그리는 환경에서 발걸음이 번갈아 정지·진행하던 원인을 수정합니다. 일시 정지 때에는 마지막으로 표시한 위치와 보간 비율을 유지합니다.

두 동물에서 같은 기본 그림을 쓰는 지상 자세가 바뀔 때 귀·머리·앞발·꼬리·웅크림 관절을 180ms 동안 연결합니다. 식빵 자세에서 기본 자세로 바뀌며 높이가 약 11픽셀 갑자기 달라지던 경우를 포함합니다. 서로 다른 그림·방향·외형이나 공중 자세를 무조건 섞지 않으며 행동 시계·물리 몸체·접촉 시각은 바꾸지 않습니다.

두 번째 동물이 움직이는 창 위에서 균형을 잡을 때 몸 전체를 기울이던 처리를 머리·몸통의 부분 동작으로 바꿉니다. 발의 실제 지지면 위치와 창의 이동은 Box2D에서 이어갑니다.

이번 변경은 2D 그림에서 다리 부분을 나누고 메시·부분 관절을 변형하는 방식입니다. 몸의 위치·중력·충돌은 Box2D로 계산하며 다리마다 별도의 Box2D 몸체를 만들지 않습니다. 새로운 3D 모델이나 완전한 골격 애니메이션을 도입한 것은 아닙니다.

## 유지하는 기록과 기능

Windows 10/11 x64, Box2D 3.1.1, 두 마리 육성·캐릭터·의상·자동 장난감과 자동 업데이트를 유지합니다. 효과음·음원·재생 기능은 추가하지 않습니다. 사용자의 포인터를 강제로 이동하거나 클릭·키 입력을 대신하지 않습니다.

생일·성장·체형·기억·친밀도·성격·외형·두 번째 동물과 업데이트 설정의 저장 형식·경로를 바꾸지 않으며 수동 데이터 변환은 필요하지 않습니다. 사용자 기록은 계속 `%LOCALAPPDATA%\YeopjariCat`에 저장합니다. 백업은 앱을 종료한 뒤 이 폴더 전체를 복사하세요.

## 공개 파일 검증

`v2.0.2` 태그와 검사한 소스는 [da08a7e87da254486e39ec7261dd5ef17803d728](https://github.com/cho-woo/yeopjari-cat/commit/da08a7e87da254486e39ec7261dd5ef17803d728)로 일치합니다. [워크플로 41946783594](https://github.com/cho-woo/yeopjari-cat/actions/runs/41946783594)의 빌드·Windows 실행·공개 작업이 모두 통과했습니다.

Windows에서는 실제 배포 EXE의 `--self-test`와 `--render-self-test`를 실행했습니다. 기존 저장·메뉴·생활·장난감 검사 외에 커서 접촉과 도약, 두 동물의 자세 연결, 10종 캐릭터·13개 의상의 보행 그림과 캐시·그리기 경로를 확인합니다. 선택한 시점과 조건을 검사한 결과이며 모든 영상 프레임이나 모든 사용자 PC 조합의 육안 검수를 뜻하지 않습니다.

공개된 다섯 파일의 크기·SHA-256을 GitHub API 및 체크섬 목록과 대조했습니다. ZIP의 여섯 항목·CRC, 단독 EXE와 ZIP 안 EXE의 동일성, 한국어 버전 정보, 릴리스 노트, 공식 업데이트 주소도 확인했습니다. 검증 시점의 공식 `latest.txt`는 `2.0.2`이며 버전 고정 피드와 같았습니다.
