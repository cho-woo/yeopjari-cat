# v1.10.3 영상 효과음 교체

이 문서는 v1.10.3의 역사적 배포 근거입니다. v2.0.1의 무음 소스에는 아래 음원·재생 코드가 포함되지 않으며, 당시 소스와 도구는 v1.10.3 태그에서 확인합니다.

사용자가 제공한 첫 영상에서 준비한 효과음을 공개 배포에 포함합니다. 공개 배포 동의를 확인했으며, 원본 영상과 전체 추출 음원은 로컬의 Git 제외 경로에 보관합니다. 저장소와 실행 파일에는 짧은 효과음 14개만 포함합니다.

## 적용 범위

기존 리소스 ID 301~314와 파일 이름을 유지하며 모든 행동 효과음을 교체합니다. 원본의 온전한 네 구간을 재사용하므로 14개의 서로 다른 울음소리를 새로 만든 것은 아닙니다. 영상 끝에서 잘린 구간은 사용하지 않습니다. 피치·속도 변경 없이 모노 PCM16/22,050Hz 변환, DC 제거, 일정한 음량 조정과 짧은 페이드를 적용합니다.

[v1.10.3의 음원 manifest](https://github.com/cho-woo/yeopjari-cat/blob/v1.10.3/assets/audio/manifest.json)에 원본·PCM·결과 해시, 구간·길이·음량·리소스 ID를 기록합니다. 사용자 제공 음원에 CC0 등 새로운 라이선스나 저작권자를 임의로 붙이지 않습니다. 실제 청취나 스피커 출력 검사를 했다는 주장은 하지 않습니다.

manifest의 `version`은 이 효과음 묶음의 도입 버전입니다. 이후 앱만 업데이트하는 경우 같은 음원 묶음의 버전을 바꿀 필요는 없습니다.

생일·성장·체형·친밀도·기억·캐릭터·성격·의상·음소거·음량·업데이트 설정의 저장 형식은 유지합니다. Box2D·표시·창 위 클릭의 v1.10.2 수정과 기존 행동별 소리 시점·재생 간격·겹침 방지를 유지합니다.

## 검증

- 로컬 원본이 있으면 원본/PCM 해시와 준비된 전체 샘플을 재검증합니다.
- 원본이 없는 공개 체크아웃에서는 고정된 출력 해시와 PCM 형식·길이·음량·페이드·구간 메타데이터를 검사하며, 원본 재구성 검사는 명시적으로 구분합니다.
- Windows의 실제 배포 EXE `--self-test`가 생산용 `Player::LoadResource`와 PCM 파서로 리소스 301~314를 모두 불러옵니다. 이 검사는 오디오 장치를 열거나 스피커 재생을 시도하지 않습니다.
- 기존 Windows GDI+·입력 검사와 전체 모델 검사, Windows x64 빌드·ZIP·업데이트 피드 검증을 유지합니다.
- 공개 후 배포 EXE의 실제 리소스 바이트를 추출해 manifest의 14개 WAV 해시와 대조합니다.

로컬 전체 `tools/check.sh`가 통과했습니다. Python 검사 27개 중 26개가 통과하고, 현재 음원이 아닌 과거 v1.5 음원 전용 검사 1개는 명시적으로 건너뜁니다. 실제 Box2D·동작·기억·저장·업데이트 회귀 검사, Windows x64 교차 빌드, ZIP·업데이트 피드 검증도 통과했습니다. [검사 로그](validation/v1.10.3-public-check.log).

공개 체크아웃에서는 포함하지 않는 원본 영상의 재구성 검사도 건너뛰며, 출력 14개의 고정 해시·형식·메타데이터 검증은 수행합니다. 로컬의 원본 대조 검사에서는 14개 전체 샘플 재구성이 통과했습니다.
