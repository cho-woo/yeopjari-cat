# v2.0.35 행동 전환 점검

## 점프 지시와 착지 회복 추가 점검

기존 일반 점프는 등록된 영상 프레임을 사용했다. 구형 자료의 단일 그림 리그 대체 분기가 원인인 것은 아니다. 다만 비행 시계가 실제 도약 속도 대신 고정된 ±200px/s를 사용해, 기본 약315px/s 도약에서 첫 비행 프레임과 마지막 프레임을 각각 약134ms 유지했다. 마지막 착지 그림도 앞발을 든 자세였고 수동 행동의 남은 기한 동안 약1초 유지한 뒤 걷기 복귀 영상으로 교체됐다.

Dropshot에서 점프·회복 영상을 네 개 더 생성했다. MiniMax H3 두 개는 재도약이 있어 사용하지 않고 원본과 요청을 남겼다. Seedance2.5 두 개는 한 번의 도약, 앞발과 뒷발의 착지, 충격 흡수, 네 발을 짚은 회복이 이어져 채택했다. 각 원본97장을 순서대로 보관하며, 불변 원화에서 유래한 등록된 옆모습을 첫·끝 조건으로 사용했다. 영상별 높이 정규화 없이 공통367px 배율을 유지한다. 생성 비용은1,240credits(미채택320 + 채택920)다.

`jump-v35` 원본, 생성 요청, 선택 프레임과 모든 프레임의 기준점은 `assets/video-actions`에 남긴다. 머리 앞부분의 고정 폭 기준으로 꼬리·다리 실루엣을 제외하고 수평 이동을 등록한다. 공중에서 영상 자체의 수직 이동을 매끄럽게 제거해 Box2D 높이가 중복되지 않도록 하며, 이륙·접촉에서는 실제 그려진 발바닥으로 연결한다. 캐릭터 픽셀이나 프레임별 크기는 변형하지 않는다.

첫 고양이와 두 번째 고양이 모두 실제 도약 충격량으로 비행 프레임을 선택한다. 명시한 점프의 착지 회복이 끝나면 남은 임의의3초·6초 기한을 기다리지 않고 기존 복귀 동작으로 이어진다. 이동 점프의 속도와 소유권, 포인터 도약의 기존 접촉 판정은 유지한다. 점프 원본의 준비·착지 재생은24fps 원본 시계를 보존하고, 공중 구간만 실제 물리 비행에 연결한다.

`--manual-motion-self-test`의 점프 검사는 세 외형 × 양방향 × 제자리/걷기 중 요청을 배포 경로로 실행한다. 1.5배 화면 배율의165px 크기로 원본 그림을 렌더링하고, 비행 프레임의 장시간 고정, 이륙 전 공중 자세, 물리 높이 중복, 착지 전 복귀와 저장 기록 변경을 검사한다. PNG 최적화를 사용할 때는 RGBA8 형식과 투명 픽셀을 포함한 모든 디코딩 바이트가 동일한지 검사한다.

현재 실행 중인 배포본이 v2.0.34임을 파일 버전으로 확인한 뒤 점검했다. 폴더 이름은 이전 버전이었으므로 폴더명으로 버전을 판정하지 않았다.

## 원인과 변경

- `DrawStyledAnimation`이 배포 외형 전체에서 경계 연결 경로를 즉시 우회했다. 식사·그루밍·꾹꾹이·파리 사냥과 기본 자세 사이에 그림이 바로 교체되었다. 조용히 바닥을 짚은 경계만 등록된 영상의 위치에 맞추어 220ms 동안 연결한다. 같은 영상 내부의 발 접촉, 실제 이동, 턴, 공중 동작은 지연시키지 않는다.
- 과거 수면 시트는 적은 수의 정지 그림을 수백 ms 이상 유지했다. 동일 원화의 앉기·웅크리기를 시작·끝 조건으로 생성한 연속 영상을 사용한다. 무기한 수면은 원본 `assets/cat.png` 6번 그림과 기존 스타일 원화를 그대로 사용한다. 깨는 동안 다른 수동 행동은 예약하고 완전한 일어나기 이후 시작한다.
- 새 버전 확인은 수동 메뉴와 무관한 백그라운드 결과를 사용한다. 30분 주기, 일시적 오류 후 5분 재시도, 확인된 버전의 지속 말풍선 및 재시작 복구를 검증한다.

## 드롭샷 원본

`assets/video-actions/generation.json`에 MiniMax H3의 신규 8개 생성, 입력 이미지, 요청 값, 결과 URL·원본 해시와 선택 사유를 보존했다. 비용은 총 1,280 크레딧이다. 잠들기·깨어나기 4개를 선택했다. 새 앞발 영상 2개는 타격 사이에 앞발을 바닥에 짚지 않아 기존의 안전한 추격 전환을 대체하지 않았다. 나머지 2개는 작은 안정 동작의 타이밍 참고용으로 보존했다.

- 원본: `assets/video-actions/sources/continuity-v35/`
- 수면 등록: `assets/video-actions/identity-v29.json`의 `sleep` 항목. 각 원본 107프레임, 24fps를 유지한다.
- 선택 프레임과 검토판: `assets/video-actions/selected/continuity-v35/selection.json`
- 변경 전 등록: `assets/video-actions/history/v34/`
- 세 외형은 공통 367px 원화 기준을 유지한다. 오드아이는 크림 원본의 알파와 피부를 바꾸지 않고 등록된 재질·홍채 마스크를 사용한다.

## 검증 범위

`RefreshAnimationTimer`가 `Sleep`·`Watch` 상태의 실제 영상과 경계 연결 중에도 40ms 절전 간격과 일반 Windows 타이머 해상도를 적용했다. 활성 영상·수면 진입·회복 경계·두 번째 고양이의 영상 재생 동안은 16ms 갱신을 유지하고, 완전히 쉰 뒤에만 줄인다. `--render-update-notice`는 실제 숨겨진 레이어 창에서 말풍선과 16→40→16ms 전환을 세 외형으로 확인한다.

로컬 GDI+ 정상 행동·물리·자세 선택과 실제 `RenderFrame` 경로에서 7개 전환 시나리오 × 3외형을 비교했다. 식사 소품의 바닥 여유 공간이 바뀔 때도 이전 그림을 같은 바닥 위치에 등록한다. 교체 첫 틱의 평균 픽셀 변화는 정규화 값 0~0.00083으로 줄어 직전 자세에서 출발하는 것을 확인했다. 이 수치는 전체 영상의 모든 움직임이 0이라는 의미가 아니다. 프레임 렌더 시간은 보고서에 함께 기록하며, 컴포지터 대기나 시스템 부하에 대한 일정한 프레임 시간 보장을 뜻하지 않는다.

`--render-boundary-review`는 동일 자세를 직접 렌더와 배포 전환 경로로 각각 그린다. `render-self-test/boundaries/report.json`과 PNG 비교를 출력한다. 사용자 프로필·OS 포인터를 사용하지 않는다. 자동 알림은 `NativeAutomaticUpdateNoticeTest`에서 메뉴 호출 없이 실제 `PollUpdates`에 성공·실패 결과를 전달한다.

추가 검증은 기존 전체 C++/Python 테스트, Windows 정상 렌더, 32개 행동의 원본 대조, 걷기·달리기·턴·점프·근거리 포인터·동반 고양이 회귀 검사를 실행한다. 공개 배포는 최종 소스의 CI 성공과 패키지·피드 검증 후 수행한다. 공인 서명 설치 파일의 홈페이지 연결은 인증서 발급과 실제 서명 검증을 마친 뒤 별도로 활성화한다.

점프의 준비 시작과 회복 완료 뒤에는 기존의 조용한 지상 턴 영상과220ms 등록 연결을 사용한다. 공중과 충격 흡수 구간에는 연결 보간을 적용하지 않는다. 원본의 접촉 자세와 시계는 그대로 유지한다. 크로마키 가장자리의 잔여 초록색은 외곽2.25픽셀에 한해 제거하며, 얼굴·눈·몸 내부에는 적용하지 않는다.

`--render-jump-review`는 같은12개 실제 경로를 고밀도로 저장하는 독립 검토 명령이다. 일반 회귀 검사는 모든 시뮬레이션·렌더 프레임을 검사하면서 필수 PNG만 저장한다. 검토 명령은 세 외형의 제자리 점프를60fps PNG로 모두 보관한다. 공중의 등록 보간 비활성, 마지막 착지 그림의 장시간 정지와 점프/지상 복귀 첫 프레임의 불연속도 검사한다.

점프 경계는 두 얼굴을 겹치는 대신, 현재 영상 한 장의 그림을 이전 지상 자세에 등록해 연결한다. 준비와 회복 완료 뒤에만 적용하며 공중 보간은 금지한다. 로컬의 전체`--self-test`는 활성 데스크톱의 최상단 창 선택 픽스처295에서 중단됐다. 수정 전의 CI 통과 패키지도 동일하게295를 반환해 로컬 창 환경 제약으로 구분했다. 이 검사를 완화하지 않으며 최종 Windows CI의 전체 검증을 배포 조건으로 유지한다.
