# v2.0.13 — 제공한 동작 시트와 재생 순서 연결

현재 검증 중입니다. 공개 최신 버전과 다운로드는 [Releases](https://github.com/cho-woo/yeopjari-cat/releases/latest)에서 확인할 수 있습니다.

## 실제 적용하는 그림

최종 제공한 원본 시트 9장에 들어 있는 실제 그림은 120컷이며 원본을 모두 보존합니다. 이 수치는 동작마다 모든 컷을 재생한다는 뜻은 아닙니다. 예를 들어 박스의 0·1번 컷은 원본에 보존하되 실제 방문 동작에서는 사용하지 않습니다. 임의의 중간 그림을 만들어 컷 수를 늘리지 않습니다. 걷기와 달리기는 한 시트의 서로 다른 구간을 사용합니다.

| 시트 | 실제 그림 수 |
| --- | ---: |
| 츄르 먹기 | 24 |
| 사료 먹기 | 12 |
| 생선 먹기 | 8 |
| 그루밍 | 16 |
| 냥냥펀치 | 12 |
| 걷기·달리기 | 16 (걷기 8 + 달리기 8) |
| 점프 | 16 |
| 박스 | 8 |
| 수면 | 8 |
| 합계 | 120 |

이 시트들은 크림 치즈냥에 적용합니다. 실버 태비냥은 기존 네 장의 온전한 보행 원화를, 나머지 여덟 캐릭터는 기존 동작 경로를 유지합니다. 새로운 시트로 바뀌는 동작과 기존 다른 자세 사이에는 원화 자체의 외형 차이가 남을 수 있습니다.

## 재생과 물리

각 동작은 표시할 컷, 컷 유지 시간, 도입·반복·마무리 구간을 명시합니다. 서로 다른 자세를 모두 같은 속도로 빠르게 순환시키는 대신 동작별 순서를 사용합니다. 그루밍은 랜덤 행동으로 시작하고, 식사·츄르·생선은 받아먹었을 때 재생하며, 박스는 실제 도착과 상호작용 상태에 연결합니다. 수면의 도입·잠·기상과 점프의 준비·공중·착지를 구분합니다.

걷기·달리기는 원화에 등록한 보폭과 실제 지상 이동 거리를 사용합니다. 멈추거나 창에 실려 가는 거리, 공중 이동은 지상 발걸음에 더하지 않습니다. 이동 속도에 따라 걷기와 달리기를 선택하며 경계에서 계속 바뀌지 않도록 서로 다른 진입·복귀 기준을 사용합니다. Box2D가 몸체 위치와 중력·도약·착지를 계속 계산합니다.

동작당 최대 256컷을 읽을 수 있도록 시트 구조와 재생기를 확장합니다. 64·128·256컷 검사는 인덱스·메모리·반복 재생 검사용 합성 자료입니다. 이 수치는 배포한 고양이 그림 수가 아닙니다.

## 원화의 한계와 추가로 필요한 그림

아래 컷 번호는 각 시트 안에서 0부터 셉니다. 이번 변경으로 모든 동작의 어색함이 해결됐다고 보장하지 않습니다. 재생 순서·시간·위치를 맞추는 것과 원화 사이에 빠진 움직임을 새로 그리는 것은 별도의 작업입니다.

| 동작 | 현재 적용과 남은 한계 | 추가로 필요한 그림 |
| --- | --- | --- |
| 박스 | 0·1번의 박스 모양과 크기가 이후 컷과 달라 실제 방문은 2~7번을 사용합니다. 나올 때의 6→5번은 고개를 내미는 모습이며 몸 전체가 박스 밖으로 나오는 동작은 아닙니다. | 같은 박스를 유지한 접근·앞발 걸치기와 몸 전체가 올라와 내려서는 퇴장 과정 |
| 잠에서 깨기 | 6→2→0번으로 연결하지만 누운 몸을 일으켜 앉는 중간 자세가 없습니다. | 눕기에서 앞발로 몸을 지탱하고 앉기까지 이어지는 자세 |
| 걷기·달리기 | 각각 8컷의 재생 단계를 실제 이동 거리와 맞춥니다. 원화 사이의 발 위치가 연속적으로 이어지거나 지지하는 발이 모든 순간 같은 지면에 고정된다고 보장하지 않습니다. | 각 보행 주기에서 접지 위치·몸통 크기·기준점을 맞춘 24~32컷과 명확한 지지·발 들기 단계 |
| 생선 먹기 | 0·1번의 생선이 발바닥보다 약 13 논리 픽셀 아래에 그려져 있습니다. 실행 시 투명한 아래 여백을 두어 고양이의 물리 기준점을 유지하므로 생선 일부가 작업표시줄 위에 겹쳐 보일 수 있습니다. | 고양이 발바닥과 동일한 지면 위에 놓인 생선과 이를 집어 드는 연결 자세 |
| 바닥의 공 건드리기 | 제공한 펀치 원화의 앞발은 지면에서 약 39 논리 픽셀 높이에 있어 바닥의 공을 때리는 자세로 쓰지 않습니다. 낮은 공을 건드리는 `ToyPaw`는 기존의 목표 위치에 맞춘 앞발 동작을 유지합니다. | 몸을 낮추고 앞발이 실제 바닥의 공에 닿는 자세와 회수 과정 |
| 다른 희귀 행동 | 이번 9장에 없는 행동은 기존 원화를 사용하므로 새 시트와 외형이 완전히 일치하지 않을 수 있습니다. | 같은 캐릭터 비율·털·시점으로 제작한 나머지 동작과 상태 사이의 연결 자세 |

논리 픽셀은 기본 성체 표시 크기를 기준으로 하며 실제 화면의 크기는 성장·표시 배율에 따라 달라집니다. 원화 전체 120컷의 표시 검사와 실제 행동 경로의 검사는 구분합니다. 원본에서 보존하고 검사하는 컷이 반드시 자동 행동에서도 선택되는 것은 아닙니다.

## 호환성

저장 형식과 생일·성장·체형·성격·친밀도·기억·선택 캐릭터·두 마리 기록을 변경하지 않습니다. 저장 마이그레이션이 필요하지 않습니다. Windows 10/11 x64, 무음과 기존 자동 업데이트를 유지합니다.

## Windows 검증과 성능 측정

검증이 끝나기 전에는 공개하지 않습니다. Windows x64 빌드·저장/커서/창 이동 회귀·실제 GDI+ 출력·ZIP·업데이트 피드·무음을 검사합니다. 실제 GDI+ 출력과 성능 측정 결과를 같은 실행 파일의 비공개 초안에 올려 확인한 뒤 공개합니다.

성능은 같은 Windows 실행 환경에서 공개된 v2.0.12 실행 파일과 후보 실행 파일을 순서대로 측정합니다. 같은 초기 저장 상태로 시작해 실행 준비 시간, 쉬는 상태, 일반 자동 행동, 캐릭터 반복 변경, 변경 후 휴식의 CPU·메모리를 비교합니다. 공개된 v2.0.12 기준 파일은 버전과 고정 SHA-256을 확인합니다.

자동 행동의 랜덤 순서는 완전히 같지 않으므로 두 실행의 행동 부하를 동일하다고 단정하지 않습니다. CPU는 한 코어 기준과 전체 논리 프로세서 기준을 구분하고, 메모리는 관찰된 private bytes·working set·운영체제 최고치와 반복 후 증가량을 기록합니다. 짧은 측정으로 장시간 메모리 누수가 없다고 보장하지 않습니다. 측정이 완료되기 전에는 절감률이나 개선 수치를 제시하지 않습니다.

실제 실행 검사는 Windows Server 2022에서 진행하며 Windows 10/11 사용자 PC의 장시간 수동 관찰과는 구분합니다. 최종 검사 실행·원본 해시·실제 출력·성능 결과·공개 파일 검증 기록은 완료 후 추가합니다.
