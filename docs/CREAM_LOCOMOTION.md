# 크림치즈냥 걷기·서기·앉기 — 작업 버전 2.0.14

사용자가 지정한 첫 단계만 변경한다. 일반 걷기/살금살금 걷기/중립 서기·앉기를 하나의 2D 파츠 리그로 연결하며, 다른 캐릭터는 선택 목록과 로딩 대상에서 제외한다. 새 캐릭터는 추가하지 않는다. 공개 릴리스는 이 작업과 별개다.

## 재생 경로

`cat_cream_motion.hpp`가 발 접지와 앉기 비율을 관리하고 `cat_cream_rig.hpp`가 공통 파츠를 렌더링한다. `main.cpp`와 `cat_companion.hpp` 양쪽에 적용했다. 이전의 걷기 8컷 교체 및 행동 사이 페이드 경로보다 우선하며, `Idle`, `Watch`, `Walk`, `Stalk`에만 사용한다. `Zoomies`와 실제 공중·착지·돌봄 포즈는 기존 경로에 남는다.

- 출발: 앉기 비율을 연속적으로 0까지 줄인 다음 모터에 이동 속도를 전달한다. 준비 시간이 걷기 구간을 소모하지 않는다.
- 보행: 보폭 18 논리 픽셀, 접지 비율 72%, 발 들기 높이 3.2 픽셀을 기준으로 네 발을 순차적으로 회수한다. 실제 화면에 사용한 Box2D 보간 위치의 지지면 상대 이동량을 사용한다. 성장과 몸 너비 배율도 보정한다.
- 정지: 마지막 발을 약 0.42초 동안 정리하고, 정지 후 약 0.65초부터 앉는다. 앉기·일어서기는 임계 감쇠 곡선으로 이어진다. 도중에 이동 요청이 바뀌어도 현재 자세와 속도에서 이어간다.
- 기준점: 파츠 좌표 지면 y=275, 출력 기준점 (193,299), 공통 높이 221. 프레임별 바운딩 박스를 다시 크기 기준으로 삼지 않는다. 얼굴과 귀는 강체로 유지한다.
- 물리: Box2D의 이동·중력·이륙·착지는 유지한다. 렌더링이 물리 위치를 덮어쓰지 않는다.

## 원화와 메모리

`assets/cream-rig-parts.png`는 기존 크림치즈냥 걷기 시트를 참고해 생성한 투명 파츠 시트다. 3열×2행 중 머리·몸통·앞다리·꼬리·뒷다리 5개를 사용하며, 마지막 예비 발 파츠는 로딩하지 않는다. 동일한 다리 파츠를 먼쪽/가까운쪽에 배치한다. 새로운 애니메이션 원화 64장/128장을 만든 것이 아니다. 기존 제공 원본 9종·120컷은 변경하지 않았다.

파츠는 시작 시 각 256×256으로 준비하고 원본 디코딩 이미지를 해제한다. 출력 버퍼 377×337과 파츠 5개의 픽셀 버퍼 합계는 약 1.74 MiB다. 활동 중 파츠 변형에 PNG 디코딩이나 힙 할당을 하지 않으며 정지한 같은 자세는 계산 결과를 재사용한다. 화면 갱신은 기존 16/40/250 ms 정책을 유지하고 자세 전환 중에만 활동 주기를 사용한다.

구 캐릭터 ID는 이전 저장을 읽기 위해 남겨 두었다. 설정을 읽을 때 외형만 Cream으로 대응한다. 예전 의상 값도 보존한다. 단독 구 캐릭터 리소스 103/104/109/111은 실행 파일에서 제외했고 캐릭터 아트 로딩 배열은 한 종류다. 공용 시트에 포함된 사용하지 않는 옛 그림과 호환용 코드까지 모두 삭제한 것은 아니다.

## 검증

- `bash tools/test.sh`: 전체 휴대용 자동 검사. 추가로 실제 Box2D에서 25/60/120 Hz, 좌우 방향, 성장/너비 배율, 출발 대기, 발 접지, 정지 후 앉기, 점프·착지 및 저장 기록 마이그레이션을 검사한다.
- `bash build.sh`: Windows x64 실행 파일 교차 빌드 및 한글 업데이트 대화상자 리소스 검사.
- `python3 tools/render_cream_motion.py`: 생산 C++ 리그와 Box2D를 사용한 480회 진행, 원본 알파 기준 경계·바닥 검사, 자세 비교 PNG와 8초 GIF 생성. 결과는 `build/cream-motion/`에 저장한다. GIF는 30fps로 내보내며 실제 진행은 60Hz다.
- `--render-self-test`에는 새 GDI+ 렌더링 검사도 추가했다. 세 가지 크기와 양방향, 연속 자세 변화, 투명도, 지면과 잘림, 구 캐릭터 리소스 제외를 검사하고 `render-self-test/cream-walk-stand-sit-gdi.png`를 출력한다. **이 Windows 전용 검사는 이번 Linux 환경에서 실행하지 못했다.**

휴대용 미리보기의 Box2D+리그 CPU 시간 표본은 `benchmark.json`에 기록한다. 이는 Windows 앱 전체 CPU·메모리나 장시간 실행 측정이 아니다. 시작 시간/실제 GDI+ 출력/고해상도 모니터/창 위 이동은 Windows에서 추가 확인해야 한다.

## 이번 범위 이후

서로 다른 방향으로 돌아서기, 달리기 연결, 정면 식사·그루밍에서 측면 서기로 돌아오는 동작, 박스·수면에서 나오기는 여전히 별도 연결 작업이 필요하다. 새 파츠 방식의 걷기·앉기와 다른 원화 행동 사이의 외형 전환까지 모두 해결했다고 보지 않는다.
