# v2.0.1 — 자동 행동과 무음

v2.0.0에서 이어지는 수정 버전입니다. 효과음과 수동 행동·장난감 선택을 없애고, 고양이가 스스로 움직이는 흐름과 실제 이동에 맞는 발걸음을 보강합니다. Windows 10/11 x64와 Box2D 3.1.1을 유지합니다.

**배포 전 검증 중입니다.** 아래 내용은 준비 소스의 변경 범위이며, v2.0.1 공개 완료나 최종 Windows 검증 통과를 뜻하지 않습니다. 현재 공개된 v2.0.0의 근거는 [이전 배포 기록](V2_0_0.md)에 보존합니다.

## 바뀐 사용 방식

- 효과음 파일·내장 음원·재생 코드·소리 메뉴를 제거했습니다. 말풍선과 화면 금 장난은 유지합니다.
- 점프·배 까기·식빵·꾹꾹이·귀·꼬리·냥냥펀치 등 동작을 직접 고르는 메뉴를 제거했습니다. 행동 선택기는 성격·기억·시간대·주변 상황에 따라 기존 행동을 자동으로 고릅니다.
- 공·박스·종이봉투·캣닢·깃털 낚싯대·쿠션의 등장·놀이·정리를 자동으로 진행합니다. 장난감 메뉴와 `Ctrl+Alt+B`를 제거했습니다.
- 밥·츄르·쓰다듬기, 캐릭터·옷장, 두 번째 동물 선택, 휴식·숨김, 성장 기록과 업데이트 설정은 유지합니다. 밥·츄르·숨김 단축키는 각각 `Ctrl+Alt+F/T/H`입니다.

이전 기록에서 ‘이 자리에서 쉬기’를 켰다면 그 선택도 유지합니다. 메뉴에서 다시 끄면 자동 이동을 이어갑니다. 커서 놀이는 ‘업무 방해 모드’를 켰을 때 작동하며, 일반 산책과 창 방문은 이 옵션을 꺼도 계속됩니다.

## 동작 수정

### 실제 이동과 발걸음

이동 중 남은 속도가 있는데 앉거나 정지한 그림을 표시하던 경로를 통일했습니다. 지면에 닿은 몸이 움직이는 동안에는 걷기 그림과 거리 기반 발걸음을 사용하고, 실제 감속이 끝나면 다음 자세를 시작합니다. 점프 착지 뒤의 감속과 두 번째 동물에도 같은 원칙을 적용합니다. 움직이는 창이 동물을 실어 옮긴 거리는 발걸음에서 제외합니다.

32개 동작에서 몸 전체를 반복 확대·축소하던 표현을 제거했습니다. 먹기·츄르·몸단장은 머리·앞발·혀의 부분 동작으로 표현하고, 꼬리 쫓기에서 몸 전체를 주기적으로 좌우 반전하던 표현도 없앴습니다. 빼꼼과 박스 안에 앉기에서는 지지면 위에 몸을 유지합니다.

### 열린 창과 커서

브라우저·탐색기 등 일반 창을 자동으로 찾는 초기 대기와 재시도를 줄이고, 현재 높이에서의 상승량·화면 여유·착지 공간을 확인하도록 보강했습니다. 실제 Box2D 도약 한계를 넘거나 착지할 공간이 없는 창에는 올라가지 않습니다.

창 위로 올라간 뒤 내려오는 순간 단방향 발판 접촉을 놓쳐 통과하던 물리 오류를 수정했습니다. 높이·상단 여유 207개 조합을 확인했으며, 700·900픽셀 높이의 창은 초당 30·60·120·144프레임에서 실제 착지와 지지를 검사합니다.

커서 반응이 감속 중 바뀐 동작 시각을 외부 명령으로 오인해 취소되던 문제를 수정했습니다. 관찰·추적·냄새 맡기·앞발 놀이·짧게 앉기의 진행을 같은 세션에서 관리합니다. 숨김·메뉴·휴식·옵션 해제와 빠르거나 멀어진 커서에 대한 취소를 유지합니다.

### 자동 장난감과 두 동물

자동 장난감은 숨김·메뉴·드래그·공중·창 위·식사·다른 상호작용을 피하고, 놀이 후 정리한 뒤 다음 기회를 기다립니다. 긴 중단 뒤 여러 장난감을 몰아서 꺼내지 않습니다. 장난감 놀이는 기존의 실제 접근·접촉·휴식 흐름과 Box2D 공 물리를 사용합니다.

두 번째 동물은 도약 준비와 착지·감속을 실제 물리 상태에 맞추고, 먹기·다른 동물과의 접촉을 정지한 발 위에서 시작합니다. 함께 뛰는 경우에도 같은 지지면과 체형에 맞는 속도를 확인합니다.

특별 희귀 시퀀스·기념일 반응·식사 요청 말풍선과 여섯 장난감의 자동 놀이는 첫 번째 동물에게 적용됩니다. 두 번째 동물의 독립 기록, 시간대별 행동 비중·기분·계절 의상과 두 동물 사이의 상호작용은 유지합니다.

### 희귀 행동의 기회 배분

펀치·재채기·꼬리 놀이의 특별 후속 반응이 하루 기회를 먼저 소진하던 편중을 줄였습니다. 후속 반응도 고정된 시간 구간의 추첨을 거쳐 작은 박스·왕관·화면 반대편 등장·장기 친밀도 시퀀스에 기회가 돌아갑니다. 프레임 수나 같은 구간의 반복 확인으로 확률이 커지지 않습니다.

하루 0~2회 기회, 최근 24시간 최대 2회, 최소 4시간 간격과 90일·1년·5년의 기간·친밀도 조건은 유지합니다. 기존 기억의 최근 희귀 행동 시각과 그 당시의 12시간 간격도 새 생활 기록에 이어집니다.

## 저장과 호환성

저장 폴더는 `%LOCALAPPDATA%\YeopjariCat`입니다. 생일·성장·영양·친밀도·기억·생활·캐릭터·의상·두 번째 동물·업데이트 기록의 스키마와 경로를 바꾸지 않습니다. 수동 마이그레이션은 필요하지 않습니다.

기존 `sound-settings.ini`와 백업은 삭제하거나 덮어쓰지 않고, 무음 버전에서는 읽거나 갱신하지 않습니다. 전체 백업은 앱을 종료하고 사용자 폴더 전체를 복사하세요. 메뉴의 성장 기록 내보내기는 첫 번째 동물의 성장 파일만 보관합니다.

## 검증 범위와 상태

| 검사 | 확인하는 내용 | 현재 상태 |
| --- | --- | --- |
| 자동 행동·생활 모델 | 수동 명령 없는 전체 행동, 커서 없는 일반 동작, 희귀 행동 분배·기간·횟수·저장 호환성 | 로컬 통합 검사 통과 |
| 커서 세션·실제 Box2D | 감속 중 소유권, 여러 프레임 속도, 숨김·옵션 전환·재개, 높은 창의 실제 접촉·착지 | 로컬 통합 검사 통과 |
| 표시·장난감·두 번째 동물 | 32개 동작의 부분 동작·발걸음, 착지 후 감속, 자동 등장·정리, 독립 돌봄·지지면 | 로컬 통합 검사 통과 |
| 무음 EXE·패키지 | 실제 PE의 음원 리소스와 재생 함수 import, ZIP·피드·버전·해시 | 최종 빌드 결과 대기 |
| Windows 네이티브 실행 | 같은 EXE의 `--self-test`와 `--render-self-test`, 실제 메뉴 구성·32개 동작 × 10종 캐릭터 × 13개 의상 GDI+ 그리기·입력 경로 | CI 결과 대기 |
| GitHub Release와 공개 다운로드 | 공개 파일·공식 피드 재다운로드, 크기·해시·ZIP 재검증 | 앞선 검증 통과 후 진행 |

`bash tools/check.sh`는 전체 모델·물리·Python 검사, Windows x64 교차 빌드, 로컬 ZIP·업데이트 피드 검증을 수행합니다. `tools/release.py`는 v2.0.1 이상에서 `tools/verify_silent_exe.py`로 실행 파일의 실제 리소스·일반 및 지연 import를 확인합니다. 타이머 해상도용 `timeBeginPeriod`·`timeEndPeriod`는 허용하며 음원·재생 API는 거부합니다. 과거 버전의 음원 포함 배포본을 소급해 잘못된 파일로 판정하지 않습니다.

네이티브 검사는 실제 제품 코드의 생활 이벤트·장난감 연결, 저장 불변성, 실제 Win32 메뉴의 남겨 둔 항목·체크 상태·제거된 명령, GDI+ 그리기와 입력 경로를 확인합니다. 모델·물리 검사와 실제 Windows 실행 결과를 구분하며, Windows 10/11의 모든 창·DPI·모니터 조합을 눈으로 검수했다는 뜻은 아닙니다. 배 까기 몸통 전환의 짧은 그림 혼합과 실제 날씨 미연동은 기존 한계로 남습니다.

## 배포 조건

최종 소스의 전체 검사·Windows x64 빌드·ZIP·업데이트 피드와 같은 EXE의 Windows 검사가 모두 통과해야 공개합니다. 공개 후에는 고정 버전 파일들과 공식 `latest.txt`를 다시 내려받아 검증하고 이 문서에 소스 커밋·워크플로·해시 기록을 추가합니다.

공식 피드는 계속 `https://github.com/cho-woo/yeopjari-cat/releases/latest/download/latest.txt`입니다. 자동 알림만으로 파일을 교체하지 않으며 사용자가 앱에서 업데이트 적용을 선택해야 합니다.
