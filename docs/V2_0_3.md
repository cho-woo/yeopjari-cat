# v2.0.3 — 착지·보행·커서 놀이 다듬기

이 문서는 v2.0.3의 구현 범위와 검증을 기록합니다. 배포 준비 중이며, Windows 실행·ZIP·피드 검사가 모두 통과한 산출물만 공개합니다.

## 변경 범위

- 창 점프 중 목적지가 옮겨져도 이전 위치에 충돌판이 남아 착지하던 오류를 수정합니다. 공중에서는 충돌판만 실제 창으로 옮기며, 동물의 위치·속도는 옮기지 않습니다. 착지를 놓치면 Box2D 중력으로 낙하합니다. 작은 연속 창 이동의 운반과 두 번째 동물에도 같은 물리를 적용합니다.
- 배 까기에서 누운 몸에 앉은 머리를 붙이던 표현을 수정합니다. 목·머리와 지지면의 관계를 누운 원본 자세에 맞춥니다. 눈·입·귀의 기준점을 맞춰 얼굴 영역을 한 덩어리로 연결하고, 구를 때 짧게 눈을 감았다 뜹니다. 누워 잘 때는 기존 눈 감은 그림의 눈꺼풀을 누운 눈 위치에 맞춰 사용합니다.
- 걷기·살금살금·달리기는 실제 이동 거리로 발을 움직이며 서로 다른 보폭과 리듬을 사용합니다. 발끝을 비트는 대신 발목 위에서 다리를 굽히고 작은 체중 이동을 더합니다.
- 업무 방해 모드에서 첫 번째 동물이 가끔 정지한 낮은 커서에 천천히 접근하고, 냄새를 맡은 뒤 앞발로 두 번 톡톡 건드립니다. 기본 OFF와 기존 설정을 유지합니다. 포인터가 빨리 움직이거나 떠나면 포기하며 옵션을 끄면 새 접촉을 중단합니다. 이미 공중이면 물리 착지까지 이어집니다.
- 창의 높이가 움직인 것을 커서의 움직임으로 오인하던 계산을 고칩니다. OS 포인터를 이동하거나 클릭하지 않습니다.
- 모든 자세에 자연스럽게 맞지 않던 의상 도형과 두 동물의 옷장을 제거합니다. 오래된 의상 선택 명령도 무시합니다. 캐릭터 선택·밥·츄르·자동 행동·장난감·두 마리 육성·무음·자동 업데이트를 유지합니다.

## 기록 호환성

생일·성장·체형·성격·기억·친밀도·캐릭터·의상 선택과 해금·업데이트 설정의 저장 형식과 경로는 그대로입니다. 의상 값은 읽고 보관하지만 화면에는 그리지 않습니다. 데이터 변환은 필요하지 않습니다. 백업은 앱을 종료한 뒤 `%LOCALAPPDATA%\YeopjariCat` 폴더 전체를 복사합니다.

## 검증

`bash tools/check.sh`는 모델·저장 호환성·실제 Box2D 테스트 후 Windows x64 빌드, ZIP, 내장 그림·무음, 업데이트 피드를 검증합니다. 게시 워크플로는 그 산출물을 Windows 2022에서 실행해 `--self-test`와 `--render-self-test`를 통과시킨 뒤에만 Release를 공개합니다.

이번 회귀 검사는 이동·크기 변경·높이 변경·닫힘에 따른 착지 실패를 30/60/120/144fps에서 다룹니다. 커서 검사에는 천천히 접근해서 실제 앞발 접촉까지 이어지는 상황, 모드 OFF·거리 이탈·빠른 움직임·중단과 재개, 창 이동 중 정지한 포인터를 포함합니다. 기존 의상 키 13개가 캐릭터 10종의 그림을 바꾸지 않는지도 실제 Windows 그리기로 확인합니다.

`python3 tools/render_gait_review.py`와 `python3 tools/render_recline_preview.py`로 실제 C++ 계산을 사용하는 보행·배 까기 미리보기를 다시 만들 수 있습니다. 마지막 화면 합성은 Pillow로 수행하며 Windows GDI+ 실행 검증과 구분합니다. 보행은 10종·3보행·3체형·25단계의 실제 그림 2,250개에서 얼굴 원본 픽셀, 발 잘림·접지를 확인했습니다.

배포와 공개 파일 재검증 결과는 완료 후 이 문서에 기록합니다.

## 한계

Box2D는 동물·공·지지면의 이동과 충돌에 사용합니다. 화면의 동물은 기존 2D 그림을 부분적으로 움직이며, 완전한 3D 골격 모델은 아닙니다. 기본 자세와 보행의 그림 교체, 좌우 방향 반전, 배 까기의 180ms 전환 중 짧은 몸·털 윤곽 혼합은 남아 있습니다. 자동 검사와 대표 시점의 시각 검토는 모든 Windows PC·DPI·프로그램 창 조합의 육안 검수를 뜻하지 않습니다.
