# v2.0.31 모션 원본 대조

대상은 드롭샷 영상 기반 17종, 등록된 원화 시트 20종, 앱의 32개 행동 상태와 공·깃털·포인터·급여·달리기 턴·가장자리 오르기의 별도 상호작용이다. 크림냥·턱시도냥·눈꽃냥을 같은 110px 기준 크기로 확인한다. 바탕화면 녹화 대신 배포 앱의 Windows GDI+ 렌더러, 명령 처리, 동작 선택, Box2D 경로를 격리된 메모리/테스트 저장소에서 실행한다. 사용자 프로필을 읽거나 실행 중인 고양이를 바꾸지 않는다.

수면·츄르와 폐기된 상자 시트는 기존 원화이며 드롭샷 영상으로 표시하지 않는다. 잔몸짓·스트레칭·표정 등은 기준 원화를 사용하는 기존 리그다. 32개 상태 중 상자 상태는 운영 중지된 상태로, 정상 디스패처가 대기로 치환하는 것도 확인한다. 가장자리 붙잡기, 공 접촉, 사냥 등은 단순 상태 지정 외에 전용 정상 경로 검사로 확인한다.

공·제동·미끄러짐·회복 등에서 움직이는 실루엣을 다시 중심 잡던 처리는 고정된 영상 좌우 원점으로 바꾼다. 달리기는 소규모 공중 자세를 매번 발바닥에 붙여 없애지 않으며, 원래 바닥을 기준으로 발이 바닥을 뚫는 것만 방지한다.

영상 속 붉은 공의 어두운 가장자리가 발밑에 남던 문제를 수정한다. 원본 공의 밝은 영역에서 연결된 어두운 테두리만 확장해 제거하며, 머리·귀·무늬의 알파가 변하지 않는 검사를 둔다. 눈꽃냥의 털 재질 변환은 소품의 등록된 색 영역을 보존한다.

## 디자인과 보존 자료

`assets/cat.png`, `assets/styled-sprites/c8-r101.png`는 변경하지 않는다. `identity-v29.json`의 공통 367px 기준과 최초·최종 참조 이미지를 유지한다. 자세별 높이로 얼굴·체형을 다시 확대하지 않는다. 눈꽃냥은 크림 원본의 기하·알파를 공유하며 홍채와 흰 털 재질만 파생한다.

원본 MP4, 생성 요청·작업 ID·크레딧 기록은 `assets/video-actions/generation.json`과 `sources/`에 남긴다. 새 연속 달리기 2건의 비용은 총 160크레딧이다. 이전 등록은 `history/v30/`에 보존한다. PNG는 픽셀을 바꾸지 않는 압축을 적용하고 배포 바이너리의 불필요한 링크 심볼을 제거하여 기존 128MiB 배포 제한을 지킨다.

## 재현

1. 배포 실행 파일로 `--render-source-audit`를 실행한다. 등록 시트 표본과 정상 행동 표본을 구분해 3외형 × (20시트 + 32상태) × 8장과 보고서를 만든다.
2. `tools/review_video_sources.py --output docs/previews/v2.0.31/source-app`으로 원본 RGB 영상 프레임과 실제 GDI+ 표본을 연결한다. 원본 행은 녹색 배경을 남기며 공통 크기·등록 원점에서 대조한다. 이는 원화 등록 대조이며 바탕화면 녹화로 표시하지 않는다.
3. `--render-self-test`, `--manual-motion-self-test`, `--render-ball-play`, `--render-cursor-play-video`, `--render-groom-review`, `--render-walk-video`, `--render-moving-jump-video`의 정상 호스트 검사를 함께 실행한다. 공 판정은 실제 발과 물리 원의 거리·한 번의 충격·비접촉 거부를 유지한다. 깃털 정상 세션은 158장을 모두 보고 회복한 뒤에만 끝나는지 확인한다.
4. 원본 시계 검사는 과속·누락을, 걷기/달리기 픽셀 검사는 반복 경계의 갑작스러운 자세 변경을 거부한다. 외형 검사는 불변 원화·공통 배율·시트 경계·투명도·세 외형의 실제 출력을 포함한다.

비교 자료와 최종 검증 결과는 [v2.0.31 미리보기](previews/v2.0.31/)에 보존한다.
