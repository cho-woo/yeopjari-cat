# v1.10.1 이동 물리와 자세 수정

v1.10.0의 기능과 저장 형식을 유지하면서 창 이동, 지면 접촉, 자세 전환을 수정합니다. 효과음은 v1.10.0 공개본의 14개 WAV 파일을 그대로 사용합니다.

## 동작 변경과 이유

창으로 이동할 때 좌표를 보간하던 방식을 실제 Box2D 도약·중력·발판 충돌로 바꿨습니다. 기존 방식에서는 그림의 점프와 물리 상태가 따로 움직이고, 움직이는 창을 따라 공중의 위치까지 강제로 바뀔 수 있었습니다. 이제 거리·높이·착지 뒤 감속 공간을 확인한 뒤 도약하며, 공중에서는 실제 속도를 유지합니다.

창 윗면은 유한한 단방향 발판입니다. 아래에서 올라갈 때는 통과하고 위에서 내려올 때 접촉합니다. 창이 이동하면 발판도 이동하며, 창이 닫히면 현재 위치와 속도에서 떨어집니다. 걷는 발의 속도와 보행 위상은 발판에 대한 상대 이동으로 계산합니다. 창 끝에서는 미리 제동하고, 화면 측벽은 설정된 천장 높이까지 이어져 높은 도약 뒤 화면 밖으로 빠지지 않게 합니다.

물리 높이는 작업표시줄을 기준으로 한 하나의 좌표로 관리합니다. 그 높이만큼 전체 그리기 창을 이동하므로 높은 점프에서도 작은 내부 그리기 영역에 고양이가 잘리지 않습니다. 창 위에 정지해 있는 상태는 공중 자세로 표시하지 않습니다. 물리는 60Hz 고정 간격과 네 번의 하위 단계로 진행하며, 250ms 이내 지연은 동작 시간과 함께 처리합니다. 메뉴·숨김·긴 중단은 두 시간을 함께 멈춥니다.

점프 정점에서는 서로 다른 그림을 겹치면서 얼굴과 귀가 이중으로 보이는 문제를 발견했습니다. 공중 동작은 하나의 기준 그림과 수직 속도에 따른 국소 앞발 관절로 연결하고, 전체 크기를 바꾸지 않습니다. 실제 고양이 미리보기에서 두 캐릭터 모두 정점 겹침이 사라진 것을 확인했습니다.

배 까기는 앉기, 옆눕기, 배 보이기를 연결합니다. 몸 전체를 크게 회전하거나 확대하던 표현을 없애고 하나의 머리 관절을 유지합니다. 귀는 같은 몸 그림에서 귀 부분만 변형하며, 꼬리 세우기·꾹꾹이·기지개·재채기에서도 불필요한 몸 전체 이동을 줄였습니다. 식빵은 얼굴을 세로로 압축하지 않고 머리 위치와 몸통을 조정합니다. 정지 행동은 실제 감속이 끝난 뒤 시작합니다.

물리 충돌체는 캐릭터 제어용 캡슐입니다. 털·귀·발을 각각 강체로 계산하지 않으며, 부분 관절과 그림 변형은 애니메이션이 처리합니다. 장난감 공은 기존 구름 모델을 유지합니다.

## 자산과 기록 호환성

기존 고양이 이미지 여섯 개는 유지합니다. 추가된 `assets/cat-recline.png`는 이미 공개된 `assets/cat.png`와 `assets/cat-silver.png`를 이미지 입력으로 사용해 제작한 눕기 자세입니다. 효과음 파일과 기존 음원의 출처 표기는 v1.10.0 공개본을 유지합니다. 실행 파일에는 기존과 같은 소리 리소스 ID를 사용합니다.

생일·성장·체형·돌봄·친밀도·기억·캐릭터·성격·의상·소리·업데이트 설정의 저장 형식과 경로를 바꾸지 않습니다. 마이그레이션은 필요하지 않습니다. 기존 Box2D와 공식 안정 버전 업데이트 피드를 유지합니다.

## 검증 방법과 상태

v1.10.1 배포 대상에서 아래 검증을 수행했습니다. 공개된 파일은 별도로 다시 내려받아 검사했으며, 이전 빌드의 실행 파일이나 검사 결과로 대신하지 않았습니다.

- `bash tools/check.sh`: 모델 검사, 실제 Box2D 검사, Windows x64 빌드, ZIP 구성·해시와 업데이트 피드 검증.
- `tests/cat_physics_test.cpp`: 실제 도약·착지, 움직이거나 사라진 발판, 천장·측벽, 고정 시간 간격과 일시정지.
- `tests/cat_motion_gate_test.cpp`: 실제 감속과 행동 시작, 발판 제거 후 낙하, 이동 발판의 상대 보행, 30/60/120 FPS와 60/200/320px/s에서 창 끝 제동. 제동을 끄면 같은 유한 발판에서 떨어지는 대조 검사도 포함합니다.
- `tests/cat_render_placement_test.cpp`: DPI 1/1.25/1.5/2/3, 음수·양수 화면 원점, 높이 0~600px, 성장 배율, 24개 행동의 지지 좌표.
- 자세·변형·머리 관절·렌더 기하 검사: 중간 자세, 관절 연속성, 지면 접촉, 귀 움직임 중 몸 픽셀 유지, 얼굴 비율과 의상 부착 위치.
- Windows CI: 배포할 동일 EXE의 `--self-test`와 `--render-self-test`를 실행해 실제 Windows/GDI+ 경로를 확인합니다. 두 검사와 패키지 검증이 모두 성공해야 배포 단계가 실행됩니다.

`tools/render_motion_preview.py`의 미리보기는 실제 C++ 자세·변형과 PNG를 사용하지만 Windows 실행 검증을 대신하지 않습니다. `tools/physics_trace.cpp`와 `tools/render_physics_trace.py`는 실제 Box2D 궤적과 여러 FPS의 결과를 확인하는 도구입니다.

`tools/check.sh`는 통과했습니다. 실제 Box2D 5,562개, 정지·창 제동 35,438개, 공중 자세 100,200개 검사와 기존 회귀 검사를 수행했습니다. Python 20개 중 19개 통과, 기존 v1.5 자료 부재 검사 1개를 명시적으로 건너뛰었습니다. Windows x64 교차 빌드·ZIP·업데이트 피드도 검증했습니다. [검사 로그](validation/v1.10.1-public-check.log) · [기존 공개 음원 동일성](validation/v1.10.1-public-audio.json).
