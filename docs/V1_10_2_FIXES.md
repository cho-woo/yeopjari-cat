# v1.10.2 창 위 입력 복구

창 위에서는 `WM_NCHITTEST`가 고양이 몸의 불투명도를 확인하기 전에 모든 입력을 `HTTRANSPARENT`로 처리했습니다. 그래서 우클릭 업데이트 메뉴와 쓰다듬기를 사용할 수 없었습니다.

고양이 몸은 기존 알파 기반 입력 판정을 사용하고, 지지하는 프로그램 창의 실제 사각형 안으로 들어가는 입력만 통과시킵니다. 마우스 누름에서는 발판을 유지하며 실제 끌기 임계값을 넘긴 순간 지지를 해제합니다. 기존 단순 클릭이 고양이를 떨어뜨리고 쓰다듬기 조건까지 무효로 만들던 문제를 함께 수정합니다.

생일·성장·체형·친밀도·기억·설정·음원·업데이트 프로토콜을 바꾸지 않습니다. v1.10.1 물리·표시 수정을 포함하며 버전을 1.10.2로 올렸습니다.

검증은 전체 `tools/check.sh`와 실제 Windows 실행·GDI+ 검사, 숨김 Win32 창을 통한 실제 hit-test/발판 유지 회귀 검사로 수행합니다. 검사 결과와 공개 자산 해시는 완료 후 기록합니다. 실제 사용자 PC에서의 수동 창 조작 검수와 자동 검사는 구분합니다.

로컬 전체 `tools/check.sh`는 통과했습니다. 실제 Box2D·동작 회귀 검사, Windows x64 교차 빌드, ZIP·후보 업데이트 피드를 검사했습니다. [검사 로그](validation/v1.10.2-public-check.log). 실제 Windows의 새 입력 검사는 배포 워크플로에서 실행하며 성공해야 공개합니다.
