## 확인한 원인과 수정 범위

v2.0.11에서는 발의 계산상 접지는 검사했지만 실제 그림의 연결은 놓쳤습니다. 원본 한 장에서 잘라 낸 앞다리의 시작점이 어깨 관절보다 낮았고, 몸통을 나중에 그리면서 남은 앞다리 윗부분까지 가렸습니다. 다리 영역을 변형하는 삼각형이 접히거나 중복해서 칠해지는 문제도 있었습니다. 그래서 발 좌표가 맞아도 앞다리가 짧은 조각처럼 보였습니다.

크림 치즈냥·실버 태비냥의 지상 보행은 원본 네 장에 그려진 몸통과 다리를 함께 표시하도록 변경합니다. 걷기·살금살금·지상 우다다에서 이 그림 순서를 공유하고, 행동이 바뀌어도 발걸음 순서를 이어갑니다. 실제 이동 거리를 사용하며 정지하거나 움직이는 창에 실려 가는 동안에는 제자리에서 걷지 않습니다. 한 보행 주기는 기준 크기에서 이동 거리 14px에 대응하며, 보행 위상은 초당 최대 12프레임의 속도로 진행합니다. 22px/s 산책의 프레임 간격은 약 159ms이고 빠른 이동의 최대 재생 속도는 프레임당 약 83ms에 해당합니다. 실제 화면 갱신 시점에 따라 표시 간격에는 차이가 생깁니다. 원본의 얼굴과 털, Box2D의 몸체 이동과 중력·착지는 유지합니다.

이 수정은 잘린 다리와 합성 경계를 없애는 데 초점을 맞춥니다. 네 장의 기존 보행 원화로 재생하므로 고속 달리기 전용 원화나 세밀한 중간 자세가 새로 생기지는 않습니다. 원화에 그려진 발은 보행 중 모든 순간에 완벽한 세계 좌표 접지를 보장하지 않습니다. 나머지 여덟 동물의 기존 보행 그림 경로는 유지합니다.

## 호환성

저장 형식, 생일·성장·체형·선택 캐릭터·성격·기억·친밀도·두 마리 기록은 변경하지 않습니다. 저장 마이그레이션이 필요하지 않습니다. Windows 10/11 x64, 무음, 기존 행동 간격·돌봄 동작과 자동 업데이트를 유지합니다.

## 실제 Windows 출력과 검증

[최종 PR 검사](https://github.com/cho-woo/yeopjari-cat/actions/runs/42180804572)가 통과했고, 병합된 배포 소스 [6a1391356ea6254ed977395e35afe5f6883f24a6](https://github.com/cho-woo/yeopjari-cat/commit/6a1391356ea6254ed977395e35afe5f6883f24a6)의 [배포 준비 검사](https://github.com/cho-woo/yeopjari-cat/actions/runs/42181180016)도 통과했습니다. Windows x64 빌드·실제 실행 파일의 저장/커서/창 이동 회귀·GDI+ 렌더링·ZIP·업데이트 피드·무음을 확인했습니다.

실제 GDI+ 렌더러로 출력한 보행 그림입니다. 각 그림은 원본 네 자세를 양방향, 기준 크기 80/110/165px로 보여 주며 마지막 줄은 실제 110px 출력의 하체를 3배 확대합니다.

- [크림 치즈냥 — 실제 Windows 보행 출력](https://github.com/cho-woo/yeopjari-cat/releases/download/v2.0.12/walk-cream-gdi.png)
- [실버 태비냥 — 실제 Windows 보행 출력](https://github.com/cho-woo/yeopjari-cat/releases/download/v2.0.12/walk-silver-gdi.png)

네이티브 검사는 두 캐릭터·네 자세·세 이동 행동·양방향·네 체형·네 기준 크기(80/90.2/110/165px)의 768개 조합을 확인했습니다. 원본 atlas에서 독립적으로 복제한 그림과 실제 렌더링의 전체 픽셀을 비교하고, 잘림·투명도·바닥 경계·기존 관절 플래그의 잘못된 개입도 검사했습니다. 나머지 여덟 동물의 기존 보행 경로 검사는 유지했습니다.

배포 준비 워크플로는 자동으로 공개하지 않고 검증한 실행 파일과 위 PNG를 같은 초안에 올렸습니다. 주 작업 에이전트와 독립 검토 에이전트가 실제 Windows 출력에서 앞다리 잘림과 목 아래 삼각형 합성 경계가 제거된 것을 확인한 뒤 그 초안을 공개했습니다. [시각 검토 기록](validation/v2.0.12-visual-review.json). 이 확인은 보고된 시각적 결함을 대상으로 하며 네 장 보행의 부드러움을 보장하는 평가는 아닙니다.

공개된 ZIP·EXE 등 기본 배포 파일 5개와 검토 PNG 2개, 공식 최신 피드를 다시 다운로드해 크기·SHA-256·ZIP CRC와 구성·버전·20개 내장 PNG·무음·검사 작업과 소스 연결을 확인했습니다. [공개 파일 검증 기록](validation/v2.0.12-published.json).

실제 Windows 실행은 Windows Server 2022의 자동 검사입니다. Windows 10/11 사용자 PC의 장시간 수동 관찰은 포함하지 않습니다.
