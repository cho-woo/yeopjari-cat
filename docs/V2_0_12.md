# v2.0.12 — 걷는 다리의 잘림 수정

현재 검증 중입니다. 공개 최신 버전과 다운로드는 [Releases](https://github.com/cho-woo/yeopjari-cat/releases/latest)에서 확인할 수 있습니다.

## 확인한 원인과 수정 범위

v2.0.11에서는 발의 계산상 접지는 검사했지만 실제 그림의 연결은 놓쳤습니다. 원본 한 장에서 잘라 낸 앞다리의 시작점이 어깨 관절보다 낮았고, 몸통을 나중에 그리면서 남은 앞다리 윗부분까지 가렸습니다. 다리 영역을 변형하는 삼각형이 접히거나 중복해서 칠해지는 문제도 있었습니다. 그래서 발 좌표가 맞아도 앞다리가 짧은 조각처럼 보였습니다.

크림 치즈냥·실버 태비냥의 지상 보행은 원본 네 장에 그려진 몸통과 다리를 함께 표시하도록 변경합니다. 걷기·살금살금·지상 우다다에서 이 그림 순서를 공유하고, 행동이 바뀌어도 발걸음 순서를 이어갑니다. 실제 이동 거리를 사용하며 정지하거나 움직이는 창에 실려 가는 동안에는 제자리에서 걷지 않습니다. 한 보행 주기는 기준 크기에서 이동 거리 14px에 대응하며, 초당 최대 12번만 그림을 바꿉니다. 22px/s 산책에서는 한 그림을 약 159ms 유지하고 빠른 이동에서도 약 83ms보다 짧게 넘기지 않습니다. 원본의 얼굴과 털, Box2D의 몸체 이동과 중력·착지는 유지합니다.

이 수정은 잘린 다리와 합성 경계를 없애는 데 초점을 맞춥니다. 네 장의 기존 보행 원화로 재생하므로 고속 달리기 전용 원화나 세밀한 중간 자세가 새로 생기지는 않습니다. 원화에 그려진 발은 보행 중 모든 순간에 완벽한 세계 좌표 접지를 보장하지 않습니다. 나머지 여덟 동물의 기존 보행 그림 경로는 유지합니다.

## 호환성

저장 형식, 생일·성장·체형·선택 캐릭터·성격·기억·친밀도·두 마리 기록은 변경하지 않습니다. 저장 마이그레이션이 필요하지 않습니다. Windows 10/11 x64, 무음, 기존 행동 간격·돌봄 동작과 자동 업데이트를 유지합니다.

## 검증 상태

검증이 끝나기 전에는 공개하지 않습니다. 로컬 회귀·Windows x64 빌드·ZIP·업데이트 피드 검사 후, 같은 실행 파일의 Windows 저장/커서/창 이동 회귀와 GDI+ 렌더링을 검사합니다. 실제 GDI+로 출력한 보행 그림을 비공개 초안의 검토 자료로 올려 잘림과 다리 연결을 확인한 뒤 공개합니다. 수치 검사 통과를 자연스러움에 대한 평가로 대신하지 않습니다.

실제 Windows 실행 검사는 Windows Server 2022에서 진행하며 Windows 10/11 사용자 PC의 장시간 수동 관찰과는 구분합니다. 최종 검사 실행과 공개 파일 검증 기록은 완료 후 추가합니다.
