옆자리 고양이 1.6.0

- Box2D 3.1.1 물리엔진을 실행 파일에 포함했습니다. 별도 엔진 설치 없이 사용할 수 있습니다.
- 걷기와 달리기에 가속·감속을 적용하고, 실제 이동 거리에 맞춰 발걸음을 재생합니다. 이동 방향을 바꿀 때도 감속한 뒤 돌아섭니다.
- 점프와 짧게 뛰어드는 동작에 중력·도약·바닥 충돌을 적용했습니다. 실제 상승·하강에 맞춰 자세를 바꾸고 착지하면 몸이 살짝 눌렸다가 돌아옵니다.
- 움직이는 동안 약 60fps를 목표로 화면을 갱신하고 물리 위치를 보간합니다. 숨기거나 메뉴를 열 때는 움직임을 멈추고, 잠들면 갱신 빈도를 낮춥니다.
- 업데이트 창의 제목·아래 안내문·버튼 한글이 깨지는 문제를 수정했습니다. 빌드와 배포 전에 실행 파일 안의 실제 한글 리소스를 검사합니다.
- 크림 치즈냥·실버 태비냥, 츄르, 귀·꼬리 동작, 냥냥펀치, 고양이 소리와 체형 변화 등 이전 기능을 이어갑니다. 생일·돌봄·캐릭터·체형·소리 설정 기록은 그대로 사용합니다.

주소가 연결된 1.3.0 이상은 우클릭 → 프로그램 업데이트 → 업데이트 확인에서 적용할 수 있습니다. 이미 실행 중인 구버전의 업데이트 창은 적용 전까지 글자가 깨져 보일 수 있습니다. 이 경우 새 ZIP을 받아 기존 고양이를 종료한 뒤 실행해 주세요.
