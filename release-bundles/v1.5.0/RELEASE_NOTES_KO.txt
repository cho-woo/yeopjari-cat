옆자리 고양이 1.5.0

- 말풍선과 행동에 맞는 짧은 고양이 소리를 추가했습니다. 실제 고양이 녹음에서 편집한 야옹·부드러운 울음·골골 소리를 사용합니다.
- 배고픔 요청, 밥·츄르를 받아먹거나 배불러서 거절할 때, 쓰다듬기와 일부 점프·냥냥펀치·잠에서 깨는 행동에 반응합니다.
- 우클릭 → 고양이 소리에서 켜기·끄기, 작게(25%)·보통(45%)·크게(70%), 미리 듣기를 선택할 수 있습니다. 기본은 작게이며 설정은 저장됩니다.
- 효과음은 겹치지 않으며 숨기기·음소거·종료 시 멈춥니다. 걷기나 귀 움직임마다 울지 않도록 재생 간격을 조절했습니다.
- Windows 전체 음량을 바꾸지 않습니다. 음원은 실행 파일에 포함되어 오프라인에서도 작동합니다.
- 기존 생일·캐릭터·식사 습관·체형·돌봄 기록을 이어서 사용합니다.

주소가 연결된 1.3.0 이상은 우클릭 → 프로그램 업데이트 → 업데이트 확인에서 적용할 수 있습니다. 이전 버전 또는 주소 없는 패키지는 새 ZIP을 받아 실행해 주세요.
