# 옆자리 고양이

일하는 동안 Windows 작업표시줄과 창 위에서 함께 지내는 작은 동물입니다. 고양이 8종과 강아지·토끼를 고르고, 두 마리를 각자의 성장·성격·기억과 함께 키울 수 있습니다.


## 다운로드와 실행

**[최신 버전 다운로드](https://github.com/cho-woo/yeopjari-cat/releases/latest)**

[2.0.11 사용자용 ZIP 바로 받기](https://github.com/cho-woo/yeopjari-cat/releases/download/v2.0.11/YeopjariCat-Windows-2.0.11.zip)

**현재 공개 정식 버전은 v2.0.11입니다.** 무관한 자동 행동 사이에 18–45초의 무작위 휴식을 두고, 진행 중인 행동을 창·장난감·생활 이벤트가 끊던 문제를 수정했습니다. 그루밍·먹기·수면의 재생 간격과 자세 연결을 다듬고, 걷는 속도에서 달리기 발 순서가 섞이던 판정을 바로잡았습니다. 기존 그림·Box2D·저장 기록·무음·자동 업데이트를 유지합니다. 고양이 우클릭 → **프로그램 업데이트 → 업데이트 확인…**에서 적용할 수 있습니다. [동작 미리보기와 검증](docs/V2_0_11.md).

실행 대상은 **Windows 10/11 x64**입니다. 사용자 ZIP의 압축을 완전히 풀고 `YeopjariCat.exe`를 실행하세요. Python이나 게임 엔진 설치는 필요하지 않습니다. 프로그램이 업데이트될 수 있도록 바탕화면·문서 폴더 등 본인이 파일을 수정할 수 있는 위치에 두세요.

`update-feed.txt`는 실행 파일 옆에 그대로 보관하세요. 고양이가 안 보이면 `Ctrl + Alt + H`를 누르거나 작업표시줄 알림 영역에서 고양이 아이콘을 확인하세요.

## 함께 지내기

| 동작 | 단축키 |
| --- | --- |
| 밥 주기 | `Ctrl + Alt + F` |
| 츄르 주기 | `Ctrl + Alt + T` |
| 잠깐 숨기기 / 다시 보이기 | `Ctrl + Alt + H` |

고양이나 알림 영역 아이콘을 오른쪽 클릭하면 먹이·캐릭터·휴식·성장 기록·업데이트 설정을 선택할 수 있습니다. 외형을 바꿔도 함께 키우던 기록은 이어집니다. 두 번째 동물은 **두 마리 함께 키우기**에서 선택한 뒤에만 생깁니다. 커서 놀이는 **업무 방해 모드**를 켜면 첫 번째 동물이 반응합니다. 가끔 낮은 곳에 가만히 둔 커서에 천천히 접근해 앞발로 톡톡 건드립니다. 의상 표시와 옷장은 v2.0.3에서 제거했으며 이전 의상 저장 값은 보존합니다.

걷기·우다다·점프·배 까기·꾹꾹이·귀·꼬리 등의 행동과 열린 창 위로 올라가기는 고양이가 스스로 선택합니다. 공·박스·종이봉투·캣닢·낚싯대·쿠션은 자동으로 등장하고 놀이 후 정리됩니다. 수동 동작·장난감 메뉴와 박스 단축키는 제거했으며, 일반 이동은 업무 방해 모드 OFF에서도 계속됩니다. **이 자리에서 쉬기**로 이동을 쉬게 하거나 다시 이어갈 수 있습니다.

가끔 앞발로 화면을 톡 쳐 잠깐 유리에 금이 간 듯한 장난을 합니다. 실제 화면이나 작업 파일을 바꾸는 동작은 아닙니다.

식사 습관에 따라 체형도 천천히 달라집니다. 계속 과식하면 통통해지고 비만이 되며, 오랫동안 굶으면 마르고 허약해집니다. 움직임과 점프도 조금 둔해집니다. 다시 규칙적으로 먹이면 적당한 체형으로 서서히 돌아옵니다. 한 번 먹였다고 갑자기 살찌거나 잠깐 놓쳤다고 바로 마르지는 않습니다.

배부르면 밥·생선·츄르를 거절하기도 합니다. 받아먹은 직후 5분 동안은 먹이 종류를 바꿔도 연달아 먹지 않습니다. 배고프면 최대 두 시간에 한 번 짧은 말풍선으로 밥을 부탁하며, 잠을 자거나 숨겨 두거나 다른 행동 중일 때는 기다립니다. 별도 팝업은 없습니다. v2.0.1부터 효과음·음원·재생 코드·소리 메뉴를 제거한 무음 버전입니다.

## 업데이트

고양이 우클릭 → **프로그램 업데이트 → 업데이트 확인…**에서 새 버전과 변경 내용을 확인하세요. 적용을 선택하면 파일을 내려받아 검증하고, 기록을 저장한 뒤 프로그램을 교체하고 다시 시작하도록 구성했습니다.

이전 버전에서 창 위 고양이의 우클릭이 되지 않으면 **작업표시줄 알림 영역의 고양이 아이콘 우클릭 → 프로그램 업데이트 → 업데이트 확인…**을 이용하세요.

자동 알림을 켜면 실행 약 30초 후와 이후 약 6시간마다 확인합니다. 새 버전의 다운로드와 적용은 직접 선택하며, 자동 알림은 같은 메뉴에서 끌 수 있습니다.

**1.2 이하 또는 업데이트 주소가 없는 개발용 패키지는 이번 ZIP을 한 번 수동으로 받아야 합니다.** 기존 고양이를 종료하고 새 ZIP을 풀어 실행하면 됩니다. 주소가 연결된 1.3.0 이상은 고양이 메뉴에서 업데이트할 수 있습니다.

## 기록과 개인정보

생일, 돌봄 기록, 선택한 캐릭터와 체형은 PC의 `%LOCALAPPDATA%\YeopjariCat`에 저장합니다. 업데이트는 이 기록을 계속 사용합니다. 1.4.0 이상으로 처음 업데이트하면 기존 생일과 돌봄 기록을 유지하고 적당한 체형에서 식사 습관 기록을 시작합니다. PC를 옮기거나 포맷하기 전에는 고양이를 종료하고 이 폴더 전체를 따로 백업하세요.

실제 날짜를 기준으로 나이가 들며, 10년이 지나거나 오랫동안 먹이를 못 줘도 죽거나 사라지지 않습니다.

고양이를 키우는 데 계정이나 인터넷은 필요하지 않습니다. 업데이트 확인·다운로드 때 GitHub에 접속하며, 성장 기록·화면 내용·키보드 입력을 전송하지 않습니다. 일반적인 HTTPS 연결에 따른 접속 정보는 서버에 전달됩니다.

## 2.0.11 — 행동 간격과 연결, 보행 충돌 수정

## 2.0.5 — 걷는 자세 수정

걷기의 좌우 발 위상 차이를 반 주기로 맞추고, 같은 쪽 뒷발 다음에 앞발이 디디도록 수정합니다. 원본 발목 주름 아래 발 전체를 고정해 둥근 발등을 보존하고, 안쪽 뒷발의 분리 경계를 실제 발가락 곡선에 맞춥니다. 앞다리·뒷다리의 과도한 뻗음을 줄이면서 걷기 속도와 보폭은 유지합니다. [실시간·4배 느린 비교](docs/V2_0_5.md#걷기-비교).

## 2.0.4 — 기존 2D 걷기·달리기 수정

원본 2D 캐릭터를 유지하고 크림·실버의 네 발을 독립적으로 움직입니다. 실제 속도에 맞춘 보폭과 발마다 기억하는 접지점으로 빠른 발 반복, 보행 전환 시 튐, 다리와 함께 끌려 내려오던 배의 털을 수정합니다. 두 동물이 같은 계산을 사용합니다. [걷기·달리기 비교 영상](docs/V2_0_4.md#움직임-비교).

실제 그림 2,250개 정적 자세와 6,120개 연속 이동 표본을 검사했고, [배포 검사](https://github.com/cho-woo/yeopjari-cat/actions/runs/41977961440)에서 Windows x64 빌드·실행·GDI+ 그리기·ZIP·업데이트 피드가 모두 통과했습니다. 공개 파일을 다시 내려받아 원본 그림 11개·무음·해시·ZIP·공식 피드를 확인했습니다. [공개 파일 검증 기록](docs/validation/v2.0.4-published.json).

## 2.0.3 — 착지·보행·커서 놀이 다듬기

## 2.0.2 — 커서 놀이와 부드러운 동작 연결

## 1.10.1 — 실제 창 이동 물리와 자세 수정

창 위로 올라갈 때 **Box2D의 도약·중력·발판 충돌**을 사용합니다. 거리·높이와 착지 뒤 감속 공간을 확인하고, 도달할 수 없는 창에는 점프하지 않습니다. 창이 움직여도 공중의 고양이 위치를 강제로 옮기지 않으며, 창이 닫히면 현재 위치와 속도에서 내려옵니다. 창 끝에서는 미리 감속하고, 움직이는 창에 실려 이동한 거리를 발걸음으로 재생하지 않습니다.

- **귀 움직임:** 같은 몸 그림에서 귀 부분만 움직여 얼굴·몸·발이 다른 그림으로 바뀌지 않습니다.
- **배 까기:** 앉기·옆눕기·배 보이기를 연결하고 하나의 머리 관절을 유지합니다. 몸 전체가 크게 회전하거나 자세 전환 중 얼굴이 겹치던 표현을 수정했습니다.
- **점프 정점:** 얼굴·귀가 이중으로 보이던 그림 혼합을 없애고 하나의 공중 자세에서 수직 속도에 따라 앞발을 움직입니다. 높은 점프에서도 고양이가 그리기 영역 밖으로 잘리지 않습니다.
- **정지와 재개:** 걷다가 앉거나 누울 때 실제 감속을 기다립니다. 메뉴·숨김 뒤 보행 위상을 이어가며, 식빵에서 얼굴이 세로로 찌그러지던 표현도 수정했습니다.

v1.10.1 당시 효과음은 **v1.10.0 공개본과 동일한 14개 파일**을 사용했습니다. 생일·성장·체형·돌봄·친밀도·기억·캐릭터·성격·의상·소리·업데이트 설정을 유지하며 기록 마이그레이션은 필요하지 않습니다.

검증 완료: [배포 워크플로](https://github.com/cho-woo/yeopjari-cat/actions/runs/41768956725)에서 Windows EXE·GDI+ 실행, ZIP과 공식 업데이트 피드 검사를 통과했습니다. 공개 파일도 다시 내려받아 해시와 EXE 내 기존 음원을 확인했습니다. [검증 기록](docs/V1_10_1_FIXES.md). 실제 Windows 10/11 사용자 환경의 화면·스피커·여러 모니터 수동 검수는 자동 검사와 구분합니다.

## 1.10.0 — 친밀도·기억·생활 패턴

밥·츄르·쓰다듬기·장난감으로 함께한 경험이 **친밀도**로 천천히 쌓입니다. 상태 창에서 현재 친밀도와 기억하는 취향을 볼 수 있습니다. 반복 클릭만으로 빠르게 올릴 수 없고, 오래 실행하지 못해도 쌓인 친밀도를 잃지 않습니다. 이전 버전의 고양이는 기존 생일과 실제 밥·츄르 기록을 바탕으로 새 기억을 시작합니다.

쓰다듬기와 츄르, 놀이 습관을 기억해 반응과 행동 빈도에 반영합니다. 친해지면 가끔 가까운 커서 쪽으로 걸어와 적당한 거리를 두고 머물며, 츄르를 자주 먹었던 고양이는 배가 고프지도, 너무 부르지도 않을 때 조용히 츄르를 부탁하기도 합니다. 생일에서 시작된 기본 성격을 유지하면서, 꾸준한 돌봄 방식에 따라 친화성·활동성·호기심·장난기가 아주 조금씩 변합니다. 한 번의 돌봄이나 긴 부재가 성격을 갑자기 바꾸지는 않습니다.

Windows의 현지 시각에 맞춰 **아침 7~10시 기지개, 점심 11~14시 배고플 때 밥 요청, 새벽 2~5시 드문 우다다**가 생활 패턴에 추가됩니다. 자거나 먹거나 숨겨져 있거나 다른 동작 중이면 기다립니다. 시간대가 됐다고 항상 행동하지는 않으며, ‘이 자리에서 쉬기’ 중에는 다가오기와 새벽 우다다를 하지 않습니다.

오래 함께하고 친밀도가 쌓이면 기존 동작을 잇는 특별한 시퀀스를 드물게 볼 수 있습니다. 조건을 채워도 즉시 재생되지는 않습니다.

| 함께한 기간·친밀도 | 해금되는 희귀 시퀀스 |
| --- | --- |
| 90일 이상·25 이상 | 꾹꾹이 → 식빵, “네 옆이 편해졌어 ♡” |
| 첫 생일 이후·45 이상 | 꼬리 세우기 → 배 까기 → 관찰 |
| 다섯 번째 생일 이후·65 이상 | 기지개 → 꾹꾹이 → 식빵 → 잠들기 |

새 친밀도·기억은 같은 저장 폴더의 `memory.ini`와 `memory.bak`에 따로 보관합니다. 기존 생일·성장·체형·캐릭터·의상·소리·업데이트 기록은 이어서 사용합니다. 기억 파일에 문제가 생기면 확인된 백업으로 복구하고, 복구할 수 없으면 원본을 남긴 채 기억 학습을 쉬도록 구성했습니다. **‘성장 기록 따로 백업하기’만으로는 친밀도까지 옮겨지지 않으므로, 고양이를 종료하고 `%LOCALAPPDATA%\YeopjariCat` 폴더 전체를 백업하세요.**

## 1.9.0 — 성격·옷장·장난감

고양이마다 **개냥이·시크냥·호기심쟁이·장난꾸러기·잠보·우다다냥** 중 하나의 성격이 생기며, 같은 캐릭터라도 행동 빈도가 달라집니다. 성격은 생일과 함께 안정적으로 유지됩니다.

랜덤 행동에 **식빵 자세, 꾹꾹이, 화면 가장자리 빼꼼, 몸 긁기, 재채기**를 추가했습니다. 일부 행동은 `우다다 → 점프 → 관찰`, `꾹꾹이 → 식빵`, `배 까기 → 몸단장`처럼 짧은 시퀀스로 이어집니다.

우클릭 → **옷장**에서 `빨간 리본`, `포근한 목도리`, `쪼꼬미 왕관`을 고를 수 있고 선택은 저장됩니다. 우클릭 → **장난감**에서 공이나 박스를 꺼내면 고양이가 가끔 다가가 공을 툭 치거나 박스에 들어갑니다. 장난감은 치울 수도 있습니다.

1.8.0의 창 위 산책, 1.7.0의 맞춤 효과음과 업데이트 알림, 1.6.0의 Box2D 물리, 기존 캐릭터·성장·체형·츄르 기능은 모두 그대로 이어집니다. 기존 1.x 저장 파일도 호환됩니다.

## 1.8.0 — 랜덤 행동과 창 위 산책

평소 행동을 더 고양이답게 섞었습니다. 걷기·우다다·점프·꼬리 쫓기·귀 움직임·꼬리를 쭉 세우는 자세와 함께, 가끔 배를 보이며 뒤집어 뒹구는 행동도 합니다. 행동에 맞는 기존 효과음을 낮은 빈도로 재생하며 자동 소리 간격과 음량·음소거 설정은 유지합니다.

가끔 같은 모니터에 창모드로 열려 있는 **브라우저·파일 탐색기·메모장 같은 일반 창의 상단 테두리**를 발판처럼 인식해 뛰어올라 걷고 다른 행동을 합니다. 최대화·최소화 창, 바탕화면, 작업표시줄, 도구 창은 발판 대상에서 제외합니다. 올라간 창이 닫히거나 최소화되면 작업표시줄 쪽 바닥으로 내려옵니다.

창 위에 있을 때는 고양이가 제목 표시줄·브라우저 탭 클릭을 가로채지 않도록 클릭을 아래 프로그램으로 통과시킵니다. 이때 고양이 메뉴가 필요하면 작업표시줄 알림 영역의 고양이 아이콘을 사용하세요. 창 자체를 활성화하거나 이동·크기 변경하지 않습니다.

1.7.0의 맞춤 효과음과 “프로그램 업데이트 해줘랴 냥!” 알림, 1.6.0의 Box2D 물리와 한국어 업데이트 창 수정, 이전 성장·체형·츄르·캐릭터 기능을 그대로 이어갑니다.

## 1.7.0 — 직접 고른 효과음과 고양이의 업데이트 알림

제공받은 효과음 11개를 점프, 인사, 배고픔·밥 요청, 밥·츄르 먹기, 귀·꼬리, 냥냥펀치에 연결했습니다. 긴 먹기 소리는 동작에 맞는 3초 안팎의 구간을 사용하고, 앞뒤 무음과 음량 차이를 조절했습니다. 밥 먹기에는 사료·생선·노가리 소리 중 하나를, 냥냥펀치에는 두 소리 중 하나를 골라 실제 동작에 맞춰 재생합니다.

기존 거절·쓰다듬기·잠에서 깰 때의 세 소리를 포함해 총 14개 효과음을 사용합니다. 귀·꼬리를 메뉴로 움직이면 전용 소리가 나며, 자동 동작에서는 가끔만 재생합니다. 단일 재생, 음량 25/45/70%, 음소거, 자동 소리 최소 1분 간격을 유지합니다. **고양이 소리 → 소리 미리 듣기**에서 새 인사 소리를 확인할 수 있습니다.

새 버전이 확인되면 고양이가 **“프로그램 업데이트 해줘랴 냥!”**이라고 말풍선으로 알려줍니다. 같은 버전은 한 번만 알리고 재시작해도 기록을 이어갑니다. 숨김·수면·먹기·점프·메뉴·다른 말풍선 중에는 기다리며, 소리가 켜져 있으면 인사 효과음을 함께 재생합니다. 자동 알림을 끄면 이 말풍선도 자동으로 나오지 않습니다. 다운로드와 적용은 직접 선택합니다.

이 말풍선은 **1.7.0을 설치한 뒤 그보다 새로운 버전이 공개됐을 때** 동작합니다. 최신 버전에는 업데이트를 요청하지 않습니다. 생일·돌봄·캐릭터·체형·소리 설정과 1.6.0의 물리 및 한글 수정도 그대로 유지합니다.

## 1.6.0 — 부드러운 움직임과 물리엔진

Box2D 3.1.1을 실행 파일에 포함했습니다. 별도 엔진 설치 없이 가속·감속, 실제 중력과 바닥·가장자리 충돌을 계산합니다. 발걸음은 실제 이동 거리에 맞춰 재생하고, 물리 계산 사이의 위치는 보간해 표시합니다. 점프와 짧게 뛰어드는 동작은 실제 수직 속도로 자세를 바꾸며, 착지하면 몸이 살짝 눌렸다가 돌아옵니다.

깨어 있을 때 약 60fps를 목표로 표시하며, 실제 속도는 PC와 Windows 상황에 따라 달라집니다. 숨김·메뉴·끌기 중에는 진행을 멈추고, 잠들면 갱신 빈도를 낮춥니다. 절전이나 긴 정지 뒤에 밀린 움직임을 한꺼번에 재생하지 않습니다.

**업데이트 창 제목·하단 안내·버튼의 한글 깨짐도 수정했습니다.** 이미 실행 중인 구버전의 창은 새 버전을 적용하기 전까지 글자가 깨져 보일 수 있습니다. 이 경우 기존 고양이를 종료하고 새 ZIP을 풀어 실행하세요. 생일, 돌봄, 캐릭터, 체형과 소리 설정은 기존 저장 폴더에서 이어갑니다.

물리 동작·보간·애니메이션·기존 기능의 자동 검사와 Windows x64 빌드를 통과했고, 실행 파일의 실제 한글 리소스 및 이미지·음원도 확인했습니다. 실제 Windows 화면에서의 체감 부드러움은 아직 직접 확인하지 못했습니다.

## 1.5.0 — 행동에 맞는 고양이 소리

실제 고양이 녹음에서 편집한 여덟 가지 짧은 효과음을 추가했습니다. 배고픔 요청, 밥·츄르를 반기거나 거절하는 반응, 쓰다듬기의 골골 소리, 일부 점프·냥냥펀치·잠에서 깨는 행동에 맞춰 재생합니다.

**고양이 우클릭 → 고양이 소리**에서 소리 켜기·끄기, 작게(25%)·보통(45%)·크게(70%), 미리 듣기를 선택할 수 있습니다. 기본은 작게이며 설정은 저장됩니다. Windows 전체 음량은 바꾸지 않습니다.

소리는 겹치지 않으며, 숨기기·음소거·메뉴·종료 시 멈춥니다. 걷기·귀·꼬리 움직임마다 울지 않습니다. 자동 행동의 소리는 최소 1분 간격으로 제한하며, 배고픔 요청의 기존 두 시간 간격도 유지합니다. 실행 파일 안에 음원이 포함되어 오프라인으로 재생합니다.

원음: [Kerzoven — Cat Purr & Meow](https://opengameart.org/content/cat-purr-meow), CC0. 배포 파일의 고지에도 출처와 편집 내용을 기록했습니다.

## 이전 기능도 모두 포함

최신 버전은 이전 기능이 포함된 누적 업데이트입니다. 이전 버전을 따로 설치할 필요가 없습니다.

- **캐릭터와 모션:** 크림 치즈냥, 사진을 참고한 실버 태비냥, 캐릭터 선택·저장, 점프, 츄르, 부드러운 걷기·귀·꼬리 동작
- **성격과 장난:** 몸단장, 기지개, 관찰, 우다다, 꼬리 쫓기, 냥냥펀치와 클릭 통과 화면 금 효과
- **성장과 저장:** 실제 생일, 10년 이상 함께 키우기, 돌봄 기록과 백업
- **1.3.0:** 새 버전 확인과 프로그램 업데이트
- **1.4.0:** 과식·결식에 따른 체형 변화와 회복, 움직임 보정, 먹이 거절, 조용하고 드문 배고픔 말풍선

회색 고양이는 **우클릭 → 캐릭터 선택 → 실버 태비냥**에서 선택합니다.

이 저장소는 사용자용 실행 파일과 유지보수용 소스를 관리합니다. 사용자 ZIP에는 개발 소스나 개인 저장 기록을 포함하지 않습니다.

현재 EXE에는 코드 서명이 없습니다. 자동 검사와 Windows 실행 결과, 실제 사용자 환경에서의 화면·스피커·업데이트 교체 수동 검증 범위는 [버전별 검증 기록](docs/V2_0_0.md)에 구분해 적습니다.


## 개발과 재빌드

개발 소스는 `src/`, 이미지는 `assets/`, 회귀 검사는 `tests/`, 개발·배포 도구는 `tools/`에 있습니다. Windows 10/11 x64 프로그램을 Linux x86_64에서 크로스 빌드합니다. 과거 음원과 관련 도구는 해당 버전의 Git 태그에 보존됩니다.

```bash
bash tools/setup.sh
bash tools/check.sh
```

설치에는 Git, curl, tar/xz, Python 3, GCC/G++, ar가 필요합니다. 고정 LLVM-MinGW와 Box2D를 내려받으며, 검사 명령은 네이티브 테스트·물리 테스트·Windows 빌드·한글 리소스·로컬 ZIP 및 업데이트 피드를 검증합니다. 결과는 `release/publish/check-*/package/`에 생성됩니다. Release를 업로드하거나 공개하지 않습니다.
